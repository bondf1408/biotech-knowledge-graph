# POX2 промотор - метанол-индуцибельная система экспрессии в Yarrowia lipolytica

## Суть
POX2 (проксисомальный оксидаза 2) промотор из Yarrowia lipolytica является сильным метанол-индуцибельным промотором, широко используемым для гетерологичной экспрессии в этом организме. Он активируется в присутствии метанола и субстратов, индуцирующих пероксисомальный метаболизм, что делает его особенно полезным для экспрессии ферментов, предназначенных для локализации в пероксисомах.

## Детали
- **Регуляция**: Сильно индуцируется метанолом (до 100-кратно по сравнению с базовым уровнем), слабо индуцируется этанолом и некоторыми жирными кислотами
- **Тканевая специфичность**: Активен в пероксисомах при индукции метанолом
- **Сила промотора**: Один из самых сильных промоторов в Y. lipolytica, сравним по активности с TEF1 при полной индукции
- **Особенности**:
  * Позволяет регулируемую экспрессию через добавление метанола в среду
  * Синергетически działa с пероксисомальными локализационными сигналами (PTS1/PTS2)
  * Полезен для разделения фаз роста (на глюкозе) и производства (на метаноле)
  * Может вызывать пероксисомальный окислительный стресс при высокой индукции
- **Последовательность промотора**: Содержит сайты связывания с метанол-индуцибельными транскрипционными факторами (например, Mxf1p)
- **Применение в каннабиноидном пути**: Особенно полезен для экспрессии ферментов с PTS1/PTS2 сигналами, локализуемых в пероксисомах для доступа к высокому пулу ацетил-CoA

## Рычаг повышения выхода
Для повышения выхода каннабиноидов через POX2 промотор можно:
- Средовые:
  * Использование метанольного фединг стратегии для индукции экспрессии
  * Сочетание с пероксисомальными сигналами для координированной локализации и экспрессии
  * Оптимизация timing метанольного добавления для разделения роста и производства
  * Добавление антиоксидантов для компенсации пероксисомального окислительного стресса
- Инженерные подходы:
  * Создание гибридных промоторов с элементами POX2 и TEF1 дляconstitutive-low + inducible-high 표현
  * Оптимизация сайтов связывания транскрипционных факторов для изменения порога индукции
  * Создание демпферных систем для плавной индукции и снижения метаболического шока
- Процессные:
  * Двухступенчатое культивирование: рост на глюкозе → индукция метанолом
  * Fed-batch подача метанола для поддержания стабильного уровня индукции
  * Использование альтернативных индукторов (этанол, жирные кислоты) для более мягкой индукции
  * Контроль уровня пероксисомального окислительного стресса через антиоксиданты в среде
