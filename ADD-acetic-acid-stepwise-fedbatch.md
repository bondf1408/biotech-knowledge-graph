# Пошаговая подача уксусной кислоты как стратегия fed-batch культивации для повышения продукции липидов и ацетил-CoA в Yarrowia lipolytica

## Суть
Пошаговая (stepwise) подача уксусной кислоты в fed-batch культивировании Yarrowia lipolytica позволяет поддерживать оптимальные концентрации этого соединения для максимальной продукции липидов и ацетил-CoA, что является критичным предшественником для малонил-CoA синтеза и, следовательно, для каннабиноидного пути (THCVA, CBGVA, DVA). Уксусная кислота может быть напрямую преобразована в ацетил-CoA через ацетил-CoA синтетазу (ACS), минуя потери углерода на гликолиз.

## Детали
- **Механизм действия**: Уксусная кислота (ацетат) активируется до ацетил-CoA ацетил-CoA синтетазой (ACS), обеспечивая прямый источник ацетил-CoA для цитозольного метаболизма. Это обходит потери углерода, связанные с преобразованием глюкозы через гликолиз и пируватдегидрогеназный комплекс. Пошаговая подача предотвращает подавление роста и метаболическое переполнение, которые возникают при высоких постоянных koncentрациях ацетата.
- **Время подачи**: Обычно начинается после исчерпания первичного углеродного источника (конец batch фазы) и продолжается в течение production фазы. Интервал подачи зависит от скорости потребления и поддержания целевой остаточной концентрации.
- **Концентрация за шаг**: Определяется так, чтобы после потребления остаточная концентрация падала до низкого уровня (например, 0.1-0.5 г/л) перед следующей дозой. Например, добавление 2 г/л уксусной кислоты каждые 12 часов при скорости потребления ~0.15 г/л/ч.
- **Влияние на каннабиноидный путь**: Повышенная продукция ацетил-CoA через прямой путь увеличивает пул малонил-CoA через ACC1 активность, обеспечивая больше строительных блоков для поликетидного синтеза каннабиноидов.
- **Преимущества перед постоянной подачей**: 
  * Снижение подавления роста на высоких концентрациях ацетата
  * Уменьшение потерь углерода на побочные продукты
  * Лучший контроль над ацетил-CoA пулом
  * Повышение эффективности использования углерода на липидную продукцию

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через пошаговую подачу уксусной кислоты в fed-batch можно:
- **Добавка в среду**:
  * Добавлять уксусную кислоту шагами (например, 1-3 г/л) каждые 6-24 часа в production фазе
  * Использовать онлайн-мониторинг остаточной уксусной кислоты для адаптивной подачи (добавлять когда концентрация падает ниже порога)
  * Комбинировать с импульсной подачей пропионата для синхронного обеспечения C2 и C3 предшественников
  * Интегрировать с глицериновым кормлением для одновременного обеспечения ацетил-CoA (через уксусную кислоту/ACS) и NADPH (через глицерин метаболизм)
- **Процессные подходы**:
  * Настроить автоматическую систему подачи на основе измерения остаточной уксусной кислоты через спектрофотометрические или электрохимические датчики
  * Использовать закон Тейсона для предсказания скорости подачи на основе биомассы и целевой остаточной концентрации
  * Интегрировать с DO-stat стратегией для поддержания достаточного аэробного метаболизма при высокой скорости подачи
  * Комбинировать с стратегиями ограничения азота для фазового разделения роста и производства

- Как пошаговая подача уксусной кислоты влияет на экспрессию и активацию ACC1 и гетерологично экспрессируемых OLS/OAC в разных условиях культивации?
- Можно ли использовать другие короткоцепочечные жирные кислоты (например, пропионат, бутирата) в пошаговом режиме для обеспечения специфических ацил-CoA предшественников?
- Как пошаговая подача уксусной кислоты взаимодействует со стратегиями пульсовой подачи сахаров (глюкоза, манноза) для обеспечения сбалансированного метаболизма и redox состояния?

## Заметки
- Данные из природы показывают, что Y. lipolytica естественно продуцирует и потребляет уксусную кислоту, что делает ее привлекательной ступенью для промышленных процессов с побочными потоками, содержащими ацетат.
- Пошаговый подход позволяет точно титровать ацетил-CoA供应 для оптимизации соотношения между продукцией липидов и каннабиноидов, preventing избыточное накопление липидов при недостаточном притоке в каннабиноидный путь.
- Для каннабиноидного производства особенно важен баланс между ацетил-CoA supply для малонил-CoA (поликетидный путь) и NADPH supply для терпеноидного пути и восстановительных шагов, который можно достичь через комбинированную подачу уксусной кислоты и глицерина.
