# Кодонная оптимизация для гетерологичной экспрессии в Yarrowia lipolytica

## Суть
Кодонная оптимизация - это подход к улучшению экспрессии гетерологичных генов в Yarrowia lipolytica путем адаптации кодонного использования гена под предпочтительные кодоны хозяина. Это повышает трансляционную эффективность, снижает нагрузку на клеточное оборудование трансляции и может значительно увеличить выход целевых ферментов каннабиноидного пути.

## Детали
- **Проблема**: Гетерологичные гены часто содержат кодоны, редко используемые в Y. lipolytica, что приводит к замедлению трансляции, рибосомальному stalled и потенциальной неправильной свертке белков
- **Решение**: Перепроектирование последовательности гена для использования оптимальных кодонов Y. lipolytica при сохранении идентичной аминокислотной последовательности
- **Особенности Y. lipolytica**:
  * Использует стандартный генетический код
  * Имеет выраженное предпочтение определенных кодонов, связанное с abundancy соответствующих tRNA
  * Предпочитает заканчивающиеся на G/C кодоны, особенно в третьей позиции
  * Избегает длинных полинуклеотидных повторов и вторичных структур в мРНК, которые могут inhibировать трансляцию
- **Процесс оптимизации**:
  1. Анализ кодонного использования целевого organism-источника
  2. Сравнение с кодонным использованием Y. lipolytica высокоэкспрессируемых генов
  3. Замена редких кодонов на предпочтительные синонимичные кодоны
  4. Проверка и устранение потенциальных проблемных последовательностей (проксимальные сайты сплайсинга, мотязы связывания рибосом, сайты признанные как вредоносные)
  5. Оптимизация GC-содержания и избегание экстремальных значений
- **Инструменты**: Доступны специализированные алгоритмы и серверы для кодонной оптимизации specific для Y. lipolytica (например, основанные на данных из Pichia pastoris, близкого родственника)
- **Валидация**: Требуется экспериментальная проверка через сравнение экспрессии неоптимизированной и оптимизированной версий гена

## Рычаг повышения выхода
Для повышения выхода каннабиноидов через кодонную оптимизацию можно:
- Средовые:
  * Использование богатых аминокислотами сред для поддержки высокой трансляционной нагрузки
  * Оптимизация pH и температуры для максимальной активности рибосом и ферментов
- Инженерные подходы:
  * Проведение кодонной оптимизации всех гетерологичных ферментов каннабиноидного пути (OLS, OAC, CsPT4, THCS, ACC1, ERG20)
  * Оптимизация регуляторных элементов (промоторы, терминаторы) в дополнение к кодону
  * Создание синтетических оперонов с оптимизированными спейсерами для коэкпрессии нескольких ферментов
  * Использование рибосомальных сайтов связывания, оптимизированных для Y. lipolytica
  * Оптимизация мРНК стабильности через удаление дестабилизирующих мотивов и добавление стабилизирующих элементов
- Процессные:
  * Индукция экспрессии в фазе медленного роста для снижения метаболической нагрузки
  * Использование inducible промоторов (hp4d) для разделения фаз роста и производства
  * Балансирование экспрессионных уровней различных ферментов пути для предотвращения накопления промежуточных метаболитов

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по кодонной оптимизации в Pichia pastoris и других промышленных дрожжах из-за отсутствия прямых измерений для Y. lipolytica в контексте каннабиноидного пути.

- Кодонная оптимизация наиболее эффективна для генов с высоким содержанием редких кодонов в исходной последовательности.
- Комбинация кодонной оптимизации с оптимизацией промоторов (TEF1, hp4d) и компартментализационными сигналами (PTS1) представляет собой мощную стратегию для максимальной экспрессии гетерологичных путей в Y. lipolytica.
