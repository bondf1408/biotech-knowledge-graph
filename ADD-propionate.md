# Пропионат как предшественник пропионил-CoA для синтеза дивариновой кислоты (DVA)

## Суть
Пропионат является внешним источником пропионильной кислоты, которая активируется до пропионил-CoA пропионат-CoA лигазой (например, продуктом гена GEN-PCS-YL-001). Пропионил-CoA служит starter unit (C3) для поликетидсинтазы (OLS/TKS) в синтезе дивариновой кислоты (DVA), которая затем превращается в каннабигеровариновую кислоту (CBGVA) и тетрагидроканнабивариновую кислоту (THCVA). Достаточное снабжение пропионатом и эффективная его активация увеличивают пул пропионил-CoA, тем самым повышая субстратную доступность для DVA-пути.

## Детали
- **Ген**: пропионат-CoA лигаза (например, продукт гена GEN-PCS-YL-001, аналог фазной лигазы из Y. lipolytica или гетерологичная экспрессия из других организмов).
- **Модификация**: overexpression пропионат-CoA лигазы под сильными конститутивными промоторами TEF1 или hp4d, терминатор XPR2, вектор pYLXP' или интеграция в геном (например, в locus ku70 или YALI0C05907g locus).
- **Кофакторы**: требует АТФ и CoA для активации пропионата до пропионил-CoA (реакция: пропионат + CoA + АТФ → пропионил-CoA + АДФ + Pi).
- **Оптимальные условия активности**: pH optimum около 7.0–7.5 для многих ацил-CoA лигаз; в ферментациях Y. lipolytica обычно используется pH-контроль CaCO3 для поддержания pH ~5.5–6.0, что может субоптимально для лигазы но компенсируется высокой экспрессией.
- **Ожидаемый эффект**: увеличение пула пропионил-CoA → повышение активности OLS/OAC с пропил-стартером → рост титров DVA и далее CBGVA, THCVA. В S. cerevisiae оверэкспрессия пропионат-CoA лигазы приводит к увеличению пропионил-CoA пула и повышению produkcji поликетидов с пропил-статером.
- **Побочные пути**: конкуренция за CoA с синтезом ацетил-CoA и малонил-CoA; потенциальная ингибиция высокими концентрациями пропионата (токсичность).

## Рычаг повышения выхода
Для увеличения уровня пропионил-CoA можно:
- Генетически:
  * Overexpression пропионат-CoA лигазы (GEN-PCS-YL-001) для увеличения активации пропионата
  * Overexpression ацетил-CoA синтетазы (ACS) для увеличения пула ацетил-CoA, который может быть преобразован в пропионил-CoA через метаболизм (менее прямой путь)
  * Удалить или понизить экспрессию конкурирующих путей ацетил-CoA (например, изменение регуляции PDC или ACS) для увеличения доступности ацетил-CoA для синтеза пропионил-CoA
- Средовые:
  * Добавка пропионата (например, sodium propionate) в концентрации 0.1-5 г/л (~1.4-68 мМ) для обеспечения субстрата без токсичности
  * Использование хелатных агентов, улучшающих bioavailability пропионата (например, цитрат в низких концентрациях)
  * Избегать сильных хелатентов (например, фитатов) в среде при работе с гетерологичной экспрессией
- Процессные:
  * Мониторинг уровня пропионата через спектроскопические методы (ИК-спектроскопия, NMR)
  * Контроль уровня экспрессии гетерологичных конструктов через западноблоттинг или флюоресценцию
  * Комбинирование с другими добавками (например, магний для ACC1, цинк для транскрипции) для поддержания общего метаболического баланса
  * Использование буферных систем, минимизирующих осаждение при рабочем pH
