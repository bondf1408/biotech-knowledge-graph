# Пантотенат (Витамин B5) как предшественник CoA для пулов ацил-CoA в Yarrowia lipolytica

## Суть
Пантотенат (витамин B5) является обязательным предшественником кофермента А (CoA), который необходим для активации короткоцепочечных жирных кислот (ацетат, пропионат, бутират) до соответствующих ацил-CoA толioesters. Достаточное обеспечение пантотенатом поддерживает пулы ацетил-CoA, малонил-CoA и пропионил-CoA, критичные для поликетидного синтеза каннабиноидов (DVA, OLA, CBGA) и терпеноидного пути через MVA путь.

## Детали
- **Механизм действия**: Пантотенат соединяется с аденином и цистеином через ферментативные шаги (пантothенат kinases, фосфопантothенат цидeилтрансфераза, депфосфорилаза) с образованием CoA. CoA затем используется ацил-CoA синтетазами (ACS, ACSL) и лигазами (например, пропионил-CoA лигаза) для формирования ацетил-CoA, пропионил-CoA и бутиryl-CoA из соответствующих кислот.
- **Источники и метаболизм**: Y. lipolytica может поглощать экзогенный пантотенат; де novo синтез пантотената в Y. lipolytica неwell documented и, вероятно, требует добавки в среду.
- **Количественные аспекты**:
  * Km пантотената для пантотенат киназы в микроорганизмах ~10-50 µM.
  * Насыщение пула CoA достигается при внешней концентрации пантотената 50-200 µM.
  * Дефицит пантотената (<5 µM) приводит к снижению общего пула CoA и ограничению ацил-CoA зависимых реакций.
- **Влияние на каннабиноидный путь**:
  * Достаточный пантотенат → увеличение пула CoA → повышенная активация ацетил-CoA, пропионата и бутирата → больше субстрата для ACS, ACC1 и пропионил-CoA лигазы → увеличение пулов ацетил-CoA, малонил-CoA и пропионил-CoA → стимуляция поликетидного и терпеноидного синтеза.
  * Дефицит пантотената → ограничение пула CoA → снижение ацетил-CoA и пропионил-CoA доступности → ограничение выхода DVA и OLA.
- **Синерия с другими добавками**: Комбинирование пантотената с биотином (для ACC1) и магнием (для OLS/OAC активации) обеспечивает комплексную поддержку поликетидного пути.

## Рычаг повышения выхода
Для увеличения пулов ацил-CoA через пантотенат можно:
- **Генетически**:
  * Overexpression пантотенат киназы (PanK) и фосфопантothенат цидeилтрансферазы (PPAT) для улучшенного CoA биосинтеза.
  * Overexpression транспортеров пантотената для увеличения внутриклеточного пула.
  * Инженерирование пантотенат зависимых ферментов с увеличенной аффинностью к пантотенату.
- **Средовые**:
  * Добавка пантотената в концентрации 20-100 мкМ для насыщения CoA пула.
  * Использование пантотенат-содержащих добавок (дрожжевой экстракт) как естественного источника.
  * Оптимизация времени добавки пантотената в фазе producteurs (после фазы роста) для минимизации метABолического負荷.
- **Процессные**:
  * Контроль концентрации пантотената в среде через регулярный анализ (например, микробиологический assay или HPLC).
  * Комбинирование с биотином и Mg²⁺ для синергетического эффекта на активацию ACC1 и доступность ацетил-CoA.
  * Использование пантотенат-бедной среды для исследований зависимости.
