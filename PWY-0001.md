# Поликетидная ветвь: butyryl-CoA + malonyl-CoA → divarinic acid

## Суть
PWY-0001 описывает биосинтетический путь формирования дивариновой кислоты (DVA) из butyryl-CoA (производного sodium butyrate) и трех молекул малонил-CoA через тетракетидный синтазный цикл, аналогичный синтезу оливетоловой кислоты но с C3-боковой цепью вместо C5. Этот путь обеспечивает производство ключевого интермедиата DVA, который является продуктом ш.1 и субстратом для ш.2 в двухштаммовой системе для синтеза THCVA.

## Детали
**Путь реакций:**
1. Активация: sodium butyrate → butyryl-CoA (катализируется butyrate-CoA лигазой)
2. Удлинение цепи: butyryl-CoA + 3 × malonyl-CoA → тетракетидный интермедиат (катализируется ketosynthase-компонентом поликетидного синтаза, например, OLS-подобного фермента) с выделением 3CO₂
3. Циклизация: тетракетидный интермедиат → дивариновая кислота (DVA) (катализируется cyclase-компонентом, например, OAC)

**Ферменты и гены:**
- Butyryl-CoA лигаза: активирует внешний但yrate для формирования butyryl-CoA стартера
- Поликетидный синтаз (PKS): обычно тип III PKS, такой как olivetolсинтаза (OLS) или аналог, использующий butyryl-CoA как стартерную единицу
- Циклаз (оливетоловая кислота циклаза, OAC):催化环闭合形成芳香环结构产生DVA

**Кофакторы и условия:**
- Требует Mn²⁺ или Mg²⁺ для активности некоторых PKS и OAC ферментов
- Оптимальный pH для многих растительных PKS/OAC: 5.5–6.5
- Требует NAD(P)H для восстановительных шагов в некоторых модификациях пути (в зависимости от конкретного PKS)
- Температурный optimum обычно 28–30°C для экспрессии в Y. lipolytica

**Сравнение с C5-путем (оливетоловая кислота):**
- Но сибтрил-CoA (C4) + 3×малонил-CoA → оливетоловая кислота (C15) через тот же тип реакции
- В DVA-покупке: пропионат-CoA (C3) + 3×малонил-CoA → дивариновая кислота (C14) — на одном углероде короче боковая цепь

## Рычаг повышения выхода
Для увеличения потока через PWY-0001 можно модифицировать субстратные пулы, экспрессию ферментов и кофакторную доступность:
- Генетически:
  * Overexpression бутират-CoA лигазы для увеличения пула butyryl-CoA из внешнего sodium butyrate
  * Overexpression ACC1 (ацетил-CoA карбоксилаза) для увеличения пула малонил-CoA
  * Overexpression или инженерирование гетерологичного butyryl-CoA-специфичного ПКС (например, модифицированного OLS или подобного фермента из растений, производящих пропионат- derivatized поликетиды)
  * Overexpression OAC (оливетоловая кислота циклаза) для эффективной циклизации поликетидного интермедиата
  * Overexpression ферментов регенерации NADPH (например, glucose-6-фосфатдегидрогеназа) если путь требует восстановительных шагов
  * Knockout или downregulation конкурирующих путей consuming ацетил-CoA (например, жирно-кислотный синтез через downregulation FASN или активация β-окисления для освоения избытка ацетил-CoA)
- Средовые:
  * Добавка sodium butyrate как источника butyryl-CoA (оптимальная концентрация обычно 0.5-5 г/л для избежания токсичности)
  * Биотин supplementation (кофактор ACC1 для увеличения малонил-CoA синтеза)
  * Магний supplementation (кофактор для некоторых PKS и OAC ферментов)
  * Pantothenate supplementation (прекурсор CoA для увеличения общего пула CoA-эстеров)
- Процессные:
  * Fed-batch или постепенная подадача sodium butyrate для поддержания субстратных уровней ниже порога токсичности
  * Контроль pH 5.5-6.5 для оптимальной активности циклаз и потенциально некоторых PKS
  * Температура 28-30°C для оптимальной экспрессии и активности гетерологичных ферментов в Y. lipolytica
  * Контроль растворенного кислорода (DO 30-50%) для баланса аэробного метаболизма энергии и восстановительной способности для поликетидного синтеза
