# Инженерия Yarrowia lipolytica для биосинтеза гераньола

## Суть
Agrawal et al. 2023 демонстрируют инженерный подход к производству гераньола (C10H18, монотерпеноидного спирта) в Yarrowia lipolytica через усиление мевалонатового (MVA) пути и инженирование фермента ERG20 (сквален синтазы) для перенаправления потока к гераньолу. Работа показывает, что overexpression ключевых ферментов MVA пути и мутант ERG20(F296W) приводит к значительному увеличению продукции гераньола.

## Детали
- **Метаболический путь**: Гераньол производится через MVA путь в цитозоле Y. lipolytica, где ацетил-CoA конденсируется в изопentenilдифосфат (IPP) и диметилаллилдифосфат (DMAPP), которые затем превращаются в герантилдифосфат (GPP) и далее в гераньол через активность гераньолсинтазы (которая может быть endogenous или экспрессируемой гетерологичной).
- **Ключевые инженерные стратегии**:
  * Overexpression ферментов MVA пути (особенно HMG1 и ERG20) для увеличения изопренового пула (IPP/DMAPP)
  * Инженирование ERG20 (сквален синтазы) через мутант F296W для снижения активности на сквален и увеличения продукции гераньола через альтернативные пути
  * Overexpression гераньолсинтазы (если не endogenous) для прямого преобразования GPP в гераньол
  * Снижение конкурирующих путей (например, downregulation ERG9 для уменьшения синтеза эргостерола)
- **Компартментализация**: Возможная локализация пути в пероксисомах через сигналы PTS1 для повышения локальной концентрации субстратов
- **Экспрессионные системы**: Использование сильных промоторов (TEF1, hp4d) и inducible систем (POX2, FBA1) для контроля экспрессии
- **Предукторы**: Обеспечение достаточного уровня ацетил-CoA через overexpression ацетил-CoA синтетазы (ACS) или ATP-citrate lyase (ACL)
- **Redox баланс**: Увеличение NADPH пула через пентозофосфатный путь для поддержания восстановительных реакций в терпеноидном biosynthesis

## Рычаг повышения выхода
Для повышения производства гераньола в Y. lipolytica через метаболическую инженерию можно:
- **Генетические модификации**:
  * Overexpression ключевых ферментов MVA пути (HMG1, tHMG1, ERG10, ERG12, ERG13, IDI1) под сильными промоторами (TEF1, hp4d)
  * Инженирование ERG20 для altered продуктной специфичности (мутант F296W для смещения продукции к гераньолу и другим монотерпеноидам)
  * Overexpression гераньолсинтазы (например, из растений или микроорганизмов) для прямого преобразования GPP в гераньол
  * Knockdown или knockout конкурирующих генов (ERG9 для эргостерола, squalene synthase для сквалена)
- **Компартментализация**:
  * Добавление PTS1 сигналов к ферментам MVA пути и гераньолсинтазе для пероксисомальной локализации
  * Оverexpression ферментов пероксисомального β-окисления для увеличения ацетил-CoA пула в пероксисомах
- **Метаболические стратегии**:
  * Усиление производства NADPH через overexpression ZWF1 и GND1 (пентозофосфатный путь)
  * Повышение утилизации ацетил-CoA через overexpression ACS и ACL
  * Использование альтернативных источников углерода (гликозан, етанол) через метаболическую инженерию
- **Процессные подходы**:
  * Двухфазное культивирование: фаза роста (оптимизированная для биомассы) segued production фазы (оптимизированная для гераньола)
  * Fed-batch подача сахара (глюкоза, гликозан) для поддержания высокого уровня ацетил-CoA и NADPH
  * Мониторинг уровня гераньола через GC-MS или in-line датчики

- Как можно оптимизировать компартментализацию гераньолсинтазы между пероксисомами, митохондриями и цитозолем для максимальной эффективности?
- Есть ли доказательства образования ферментомных комплексов (метabолинов) в терпеноидном пути Y. lipolytica, и как их можно усилить для повышения эффективности гераньол производства?
- Как pós-трансляционные модификации (фосфорилирование, убиквитинация) влияют на активность и стабильность ключевых терпеноидных ферментов в Y. lipolytica при высокой экспрессии?
- Какие стратегии можно использовать для преодоления токсичности высоких концентраций гераньола, особенно considerando его летучести и потенциального влияния на мембраны клетки?

## Заметки
- Эта работа предоставляет конкретную стратегию для производства монотерпеноидов в Y. lipolytica, которая может быть адаптирована для других терпеноидов, включая геранิลдифосфат (GPP) - предшественник для каннабиноидного biosynthesis.
- Учитывая, что каннабиноидный biosynthesis требует GPP для prenylation дивариновой кислоты (DVA) в каннабигеровую кислоту (CBGA), стратегии по повышению производства терпеноидов из этой работы непосредственно применимы для увеличения GPP пула в каннабиноидном пути.
- Сочетание стратегий из этой работы (overexpression MVA пути, инженирование ERG20) с конкретными модификациями каннабиноидного пути (такие как overexpression OLS/OAC/CsPT4/THCAS) может привести к значительному повышению продуктивности каннабиноидов в Y. lipolytica.
- Работа демонстрирует, что Y. lipolytica может быть эффективной платформой для производства ценных монотерпеноидов, таких как гераньол, который имеет применение в парфюмерии, ароматизаторах и как предшественник для других соединений.
