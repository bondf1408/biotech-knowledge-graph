# Де novo биосинтез каннабиноидов в Yarrowia lipolytica

## Суть
Hong et al. 2025 демонстрируют Yarrowia lipolytica как полноценную платформу для де novo синтеза каннабиноидов и их аналогов. Ключевым открытием является использование биомолекулярных конденсатоподобных двойных систем для увеличения локализации ферментов пути и повышения эффективности синтеза каннабиноидов. Это предоставляет новую стратегию для оптимизации каннабиноидного пути в Y. lipolytica через пространственную организацию ферментов.

## Детали

### Ключевые находки
- **Платформа Y. lipolytica**: Демонстрируется способность Y. lipolytica производить каннабиноиды и их аналоги с нуля из простых углеродных источников
- **Биомолекулярные конденсаты**: Использование двойных систем для создания микрокомпартментов, которые увеличивают локальную концентрацию ферментов и субстратов
- **Оптимизация предшественников**: Вероятно включает данные по оптимизации ацетил-CoA, малонил-CoA и пропионил-CoA пулов для поддержки каннабиноидного пути
- **Ферментативная эффективность**: Повышение локализации ферментов через конденсаты приводит к увеличению эффективности каннабиноидного синтеза

### Метаболические пути и ферменты
- Оливетол-синтаза (OLS): тетракетид-синтаза для производства тетракетидов
- Оливетоловая кислота циклаза (OAC): циклизация тетракетида в оливетоловую кислоту
- Каннабигеролпрегненилтрансфераза (CsPT4): прегненилирование OLA/OA для производства CBGA/CBGVA
- THCA синтаза (THCAS): окислительно-циклизирующее преобразование CBGA/CBGVA в THCA/THCVA
- Изопреноидный путь (MVA): производство GPP для прегненилирования
- Поликетидный путь: производство малонил-CoA и ацетил-CoA для прекурсоров

### Биомолекулярные конденсаты
- **Двойные системы**: Использование пар связывающих доменов для формирования микрокомпартментов
- **Локализация ферментов": Направленная локализация OLS, OAC, CsPT4 и THCAS в конденсаты для повышения эффективности пути
- **Увеличение локальной концентрации": Конденсаты создают микросреды с высокой концентрацией ферментов и субстратов
- **Снижение диффузионных ограничений": Уменьшение расстояния между последовательными ферментами в пути

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через биомолекулярные конденсаты можно:
- Генетически:
  * Экспрессия ферментов каннабиноидного пути (OLS, OAC, CsPT4, THCAS) с фузионными связывающими доменами для локализации в конденсаты
  * Экспрессия пар linkerdomains для формирования регулируемых микрокомпартментов в цитозоле
  * Оптимизация соотношения связывающих доменов для достижения максимальной эффективности конденсатообразования
  * Инженерирование linkerdomains для чувствительности к метаболическим сигналам (pH, redox состояние, концентрация метаболитов)
  * Коэкспрессия ферментов upstream пути (акцетил-CoA карбоксилаза, малонCoA синтетаза) для увеличения пула предшественников в конденсатах
- Средовые:
  * Оптимизация времени индукции экспрезии связывающих доменов в conjunction с фазой производства
  * Регулирование концентрации исходных углеродных источников (глюкоза, этанол, жирные кислоты) для поддержания метаболического пула
  * Модуляция условий стресса (осмотический, температурный, pH) для влияния на формирование и стабильность конденсатов
  * Оптимизация уровня растворенного кислорода для поддержания активности THCAS и других оксидаз
- Процессные:
  * Fed-batch стратегия с импульсной добавкой предшественников (пропионат, ацетат) в фазу производства
  * Двухфазное культивирование: рост на стандартных источниках углерода, производство на оптимизированной среде с индукцией конденсатообразующих систем
  * Мониторинг образования конденсатов через флуоресцентную микроскопию и корреляция с уровнем продукции каннабиноидов
  * Использование компонентов, модулирующих фазовый раздел (например, изменение ионной силы, температуры, pH) для регулирования активности конденсатов

- Как посттрансляционные модификации (фосфорилирование, ацетилирование) влияют на способность ферментов участвовать в биомолекулярном конденсатообразовании?
- Есть ли доказательства естественного конденсатообразования каннабиноидных ферментов в Y. lipolytica и как его можно усилить через инженерирование?

## Заметки
- [INFERRED]: Многие параметры экстраполированы из Hong et al. 2025 и данных по биомолекулярному condensate образованию в других микроорганизмах из-за отсутствия прямых измерений в Y. lipolytica.
- Требуется экспериментальная валидация влияния биомолекулярных конденсатов на производство конкретных каннабиноидных продуктов (THCVA, THCA, CBDA и т.д.) в Y. lipolytica.
- Стратегия использования биомолекулярных конденсатов представляет собой передовый подход для метаболической инженерии в Y. lipolytica, позволяющий преодолеть диффузионные ограничения и увеличить эффективность многокомпонентных биосинтетических путей.
- Подход с биомолекулярными конденсатами может быть особенно эффективен в сочетании с другими стратегиями optimization (пулы кофакторов, предшественников, экспрессии ферментов) для синергетического эффекта на производство каннабиноидов.
