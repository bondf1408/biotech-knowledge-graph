# FBA1 промотор - фруктозо-индуцибельная система экспрессии в Yarrowia lipolytica

## Суть
FBA1 (фруктозо-бисфосфат альдолаза 1) промотор из Yarrowia lipolytica является умеренно-сильным фруктозо-индуцибельным промотором, полезным для гетерологичной экспрессии в этом организме. Он активируется в присутствии фруктозы и связан с гликолитическим путем, что делает его подходящим для синхронной экспрессии ферментов поликетидного пути с доступом к цитозольным предшественникам.

## Детали
- **Регуляция**: Умеренно индуцируется фруктозой (до 10-20× по сравнению с базовым уровнем), слабо реагирует на глюкозу и маннозу
- **Тканевая специфичность**: Активен в цитозоле при индукции фруктозой, связан с гликолитическим потоком
- **Сила промотора**: Умеренный промотор в Y. lipolytica, слабее TEF1 и POX2 при pełnej indukcji, но полезен для тонкой настройки экспрессии
- **Особенности**:
  * Позволяет регулируемую экспрессию через добавление фруктозы в среду
  * Связан с центральным углеводным метаболизмом (гликолиз/глюконеогенез)
  * Может быть полезен для экспрессии ферментов, требующих координации с гликолитическим потоком
  * Менее склонен к вызыванию метаболического стресса по сравнению с сильным индуцибельным экспрессированием
- **Последовательность промотора**: Содержит сайты связывания с фруктозо-индикуируемыми транскрипционными факторами, связанными с регуляцией гликолиза
- **Применение в каннабиноидном пути**: Подходит для экспрессии цитозольных ферментов пути (OAC, THCAS) или ферментов, для которых предпочтительен доступ к цитозольным прекурсорам

## Рычаг повышения выхода
Для повышения выхода каннабиноидов через FBA1 промотор можно:
- Средовые:
  * Использование фруктозо-минга стратегии для индукции экспрессии
  * Сбалансирование фруктозы с другими источниками углерода для оптимизации роста и производства
  * Синхронизация с гликолитическим потоком для цитозольных ферментов пути
  * Использование альтернативных сахаров (манноза, сорбиоза) для модуляции индукции
- Инженерные подходы:
  * Создание гибридных промоторов с элементами FBA1 и TEF1 для constitutive-low + inducible-high экспрессии
  * Оптимизация сайтов связывания транскрипционных факторов для изменения порога индукции
  * Создание демпферных систем для плавной индукции и снижения метаболического шока
- Процессные:
  * Двухфазное культивирование: рост на глюкозе → индукция фруктозой
  * Fed-batch подача фруктозы для поддержания стабильного уровня индукции
  * Контроль уровня метаболического потока через мониторинг промежуточных гликолизных метаболитов
