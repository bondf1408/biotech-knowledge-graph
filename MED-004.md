# Влияние температуры на каннабиноидный биосинтез в Yarrowia lipolytica

## Суть
Разные ферменты каннабиноидного пути имеют различный температурный оптимум, что создает проблему для одновременной оптимизации всех шагов пути. Особенно критично отличие температурного оптимума THCAS от оптимальной температуры роста Y. lipolytica. Это может требовать двухстадийного температурного контроля: сначала рост при оптимальной температуре для биомассы, затем изменение температуры для производства ключевых каннабиноидов.

## Детали
- **THCAS (THCA синтаза)**: Температурный optimum ~25–30°C (см. ENZ-THCS), FAD-зависимая оксидоредуктаза, катализирующая окислительно-циклизирующее превращение CBGVA → THCVA. Растительные аналоги часто показывают optimum при более низких температурах.
- **OAC (оливетоловая кислота циклаза)**: Температурный optimum ~28–32°C (см. ENZ-OAC), Mg²⁺/Mn²⁺-зависимая циклаза, катализирующая превращение тетракетида → оливетоловая кислота.
- **CsPT4 (ароматический фенилпренилтрансфераза)**: Температурный optimum ~28–32°C (см. ENZ-CsPT4), мембранно-ассоциированная prenyltransferase, катализирующая CBGA/CBGVA синтез.
- **OLS (оливетол-синтаза/тетракетид-синтаза)**: Температурный optimum ~28–32°C (см. ENZ-OLS), тип III поликетидсинтаза, катализирующая kondensaciya пропионил-CoA + малонил-CoA → тетракетид.
- **ACC1 (ацетил-CoA карбоксилаза)**: Температурный optimum ~30–35°C (см. ENZ-ACC1), биотин-зависимая карбоксилаза, производящая малонил-CoA из ацетил-CoA.
- **ERG20 (GPP/FPP синтаза)**: Температурный optimum ~30–37°C (см. ENZ-ERG20), Mg²⁺-зависимая prenyltransferase, производящая изопреновые доноры.
- **Оптимальная температура роста Y. lipolytica**: Обычно 28–30°C для большинства штаммов при наличии глюкозы как углеродного источника.
- **Влияние температуры на стабильность ферментов**: Высокая температура (>37°C) может приводить к денатурации и потере активности ферментов пути.
- **Влияние температуры на скорость роста и продуктивность**: Скорость роста обычно увеличивается с температурой до оптимума, затем снижается; продуктивность может иметь distinct optimum.
- **Двухстадийный температурный контроль**: Стратегия, при которой фаза роста биомассы происходит при оптимальной температуре для роста (~28–30°C), а фаза производства продукта — при температуре, оптимальной для ключевых ферментов пути.

## Рычаг повышения выхода
Для оптимизации температуры для каннабиноидного производства можно:
- Среды:
  * Использование двухстадийного температурного контроля: рост при 28–30°C (оптимальный для биомассы), затем снижение до 25–28°C для производства THCVA и других конечных продуктов
  * Поддержание однородной температуры в ферментере через эффективную систему перемешивания и теплообмена
  * Использование термоизолированных ферментеров для минимизации тепловых потерь и градиентов температуры
  * Контролируемое охлаждение/нагрев через рубашки или змеевики в ферментере
  * Выбор термостойких штаммов Y. lipolytica с измененным температурным профилем роста
- Инженерные подходы:
  * Экспрессия термостойких вариантов ферментов через directed evolution или рациональный дизайн (особенно для THCAS при низких температурах)
  * Экспрессия тепловых шоковых белков или chaperonов для повышения стабильности ферментов при повышенных температурах
  * Локализация термочувствительных ферментов в компартментах с более стабильной температурой
  * Использование терморегулируемых промоторов для температурно-зависимой экспрессии ключевых генов пути
- Процессные:
  * Регулярный мониторинг температуры в реальном времени с автоматическим регулированием охлаждения/нагрева
  * Оптимизация времени переключения между фазами роста и производства на основе temperature-shift экспериментов
  * Поддержание стабильных условий pH при изменении температуры (так как pH.optima могут shifts с температурой)
  * Избегание резких температурных переходов, которые могут вызывать тепловой шок и снижать viability

- Каков оптимальный профиль температурного изменения во времени для максимального выхода THCVA при учете как роста биомассы, так и продуктивного метаболизма?

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по растительным и грибковым аналогам ферментов из-за отсутствия прямых измерений в Y. lipolytica.
- Требуется экспериментальная валидация температурного оптимума и термостабильности для всех ключевых ферментов пути (THCAS, OAC, CsPT4, OLS, ACC1, ERG20) в Y. lipolytica.
- Учитывая, что оптимальная температура активности THCAS (25–30°C) лежит в диапазоне типичной температуры роста Y. lipolytica (28–30°C), двухстадийный температурный контроль может быть менее критичным, чем pH-контроль, но все же полезен для тонкой настройки производства.
- Стратегия двухстадийного температурного контроля аналогична используемой для производства некоторых терпенов в микроорганизмах, где понижение температуры после фазы роста повышает выход целевых продуктов.
- Температура может влиять не только на активность ферментов, но и на их экспрессию, стабильность, локализацию, скорость транскрипции и трансляции, а также на общий метаболический статус клетки.
