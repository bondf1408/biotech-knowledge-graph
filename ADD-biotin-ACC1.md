# Биотин (Vitamin B7) как кофактор ACC1 для производства малонил-CoA

## Суть
Биотин является необходимым кофактором ацетил-CoA карбоксилазы (ACC1), которая катализирует синтез малонил-CoA из ацетил-CoA. Малонил-CoA является ключевым строительным блоком для поликетидного синтеза, включая производство дивариновой кислоты (DVA) и оливетоловой кислоты (OLA). Достаточное обеспечение биотином критично для поддержания высокого потока через поликетидный путь в Y. lipolytica для производства каннабиноидов.

## Детали
**Биохимическая роль:**
- Биотин covalently связан с лизиновым остатком в центре ACC1 через амидную связь
- Служит переносом карбоксильной группы в реакции карбоксилазы
- Требуется для активности ACC1 в превращении ацетил-CoA в малонил-CoA
- Дефицит биотина приводит к накоплению ацетил-CoA и снижению малонил-CoA пула

**Источники и метаболизм:**
- Y. lipolytica может использовать экзогенный биотин как преформ
- Биотин может синтезироваться де novo из пимата и цистеина (путь требует подтверждения в Y. lipolytica)
- Транспортеры биотина в Y. lipolytica не хорошо изучены

**Количественные аспекты:**
- Km биотина для ACC1 в микроорганизмах обычно в диапазоне 0.1-5 µM
- Vmax ACC1 увеличивается пропорционально концентрации биотина до точки насыщения
- Избыток биотина (>50 µM) обычно не подавляет рост, но может не давать дополнительного эффекта

**Влияние на каннабиноидный путь:**
-Достаточный биотин → увеличение пула малонил-CoA → повышенная доступность для ПКС → увеличение продукции DVA/OBC
-Дефицит биотина → снижение малонил-CoA → ограничение поликетидного синтеза → снижение выхода каннабиноидов

## Рычаг повышения выхода
Для увеличения пула малонил-CoA через биотин можно:
- Генетически:
  * Overexpression биотин-лигазы (BioA/YbioB) для улучшенного биотинирования ACC1
  * Overexpression транспортеров биотина для увеличения внутриклеточного пула
  * Overexpression или инженерирование ACC1 с увеличенной аффинностью к биотину
- Средовые:
  * Добавка биотина в концентрации 5-50 мкМ для насыщения ACC1
  * Использование биотин-содержащих добавок (дрожжевой экстракт) как естественного источника
  * Оптимизация времени добавки биотина в фазе producteurs (после фазы роста)
- Процессные:
  * Контроль концентрации биотина в среде через регулярный анализ
  * Комбинирование с пантотенатом для поддержания общего пула CoA
  * Использование биотин-бедной среды для исследований зависимости
