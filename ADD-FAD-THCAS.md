# FAD/Рибофлавин (Vitamin B2) как кофактор THCAS для oksidoциклизации

## Суть
FAD (flavin adenine dinucleotide) является простетической группой THCA-синтазы (THCAS), FAD-зависимой оксидоредуктазы, которая катализирует oksidoциклизацию каннабигероварной кислоты (CBGVA) в тетрагидроканнабивариновую кислоту (THCVA). Рибофлавин (витамин B2) является предшественником в биосинтезе FAD. Достаточное обеспечение FAD критично для активности THCAS и, следовательно, для производства THCVA в двухштаммовой системе Y. lipolytica.

## Детали
**Биохимическая роль FAD в THCAS:**
- FAD covalently или некovalentли связан с THCAS в качестве простетической группы
- Принимает электроны от CBGVA во время оксидоциклизационного цикла, восстанавливаясь до FADH₂
- FADH₂ затем реокисляется молекулярным кислородом (O₂), производя перекись водорода (H₂O₂) или другие активные формы кислорода
- Цикл окисления-восстановления FAD/FADH₂ необходим для кателектической активности THCAS
- Дефицит FAD приводит к инактивации THCAS и накоплению CBGVA промежуточного метаболита

**FAD биосинтез и метаболизм в Y. lipolytica:**
- Y. lipolytica может синтезировать FAD де novo из рибофлавина (витамина B2), АТФ и GTP
- Рибофлавин фосфокиназа рибозил- превращает рибофлавин в FMN (flavin mononucleotide)
- FAD синтетаза затем аденилирует FMN для формирования FAD, используя АТФ
- Y. lipolytica также может использовать экзогенный FAD или рибофлавин через транспортеры

**Количественные аспекты:**
- Km рибофлавина для рибофлавин киназы в микроорганизмах обычно в диапазоне 1-10 µM
- Vmax FAD синтеза увеличивается с концентрацией рибофлавина до точки насыщения
- Обычная концентрация рибофлавина в среде для дрожжевых культур: 0.5-5 мкг/мл (~1-10 µM)

**Влияние на каннабиноидный путь:**
- Достаточный FAD/рибофлавин → активированная THCAS → эффективная oksidoциклизация CBGVA → повышенный выход THCVA
- Дефицит FAD/рибофлавина → инактивированная THCAS → накопление CBGVA → снижение выхода THCVA
- Особенно критично на последнем шаге пути DVA → CBGVA → THCVA

## Рычаг повышения выхода
Для увеличения выхода THCVA через FAD можно:
- Генетически:
  * Overexpression рибофлавин киназы (ribF) для увеличения фосфорилирования рибофлавина
  * Overexpression FAD синтетазы (ribE) для увеличения синтеза FAD из FMN
  * Overexpression транспортеров рибофлавина/FAD для увеличения внутриклеточного пула
  * Инженерирование THCAS с увеличенной аффинностью к FAD или улучшенной каталитической эффективностью
- Средовые:
  * Добавка рибофлавина в концентрации 5-50 мкМ для насыщения путей FAD биосинтеза
  * Прямая добавка FAD (менее стабилен) или рибофлавина-5'-фосфата (FMN)
  * Использование рибофлавин-содержащих добавок (дрожжевой экстракт) как естественного источника
  * Оптимизация времени добавки в фазе производства THCAS
- Процессные:
  * Мониторинг уровня FAD в клетках через флуоресцентный анализ или анализ кофактора
  * Обеспечение достаточного снабжения O₂ как акцептора электронов в реакции THCAS
  * Комбинирование с заправледониками NADPH для регенерации FADH₂ обратно в FAD
  * Контроль pH 4.5-5.5 для оптимальной активности THCAS (зависит от протонирования состояния FAD)
