# Metabolic engineering of Yarrowia lipolytica for terpenoids production: advances and perspectives

## Суть
Zhang et al. 2022 предоставляют всесторонний обзор достижений и перспектив метаболической инженерии Yarrowia lipolytica для производства терпеноидов. Работа рассматривает стратегии повышения продуктивности терпеноидов через оптимизация мевалонатового (MVA) и немевалонатового (MEP) путей, инженерный подход к ключевым ферментам, компартментализацию и снижение метаболической нагрузки.

## Детали
- **Метаболические пути для терпеноидов**: Y. lipolytica naturally produziert терпеноиды через MVA путь в цитозоле, с возможной компартментализацией в пероксисомах для определенных терпеноидов
- **Ключевые ферментические инженерные подходы**:
  * Overexpression ferментов MVA пути (HMG1, ERG10, ERG12, ERG20, ERG13, IDI1) для увеличения изопренового пула
  * Инженирование ERG20 (сквален синтазы) для снижения обратной связи и увеличения продукции специфичных терпеноидов
  * Оverexpression ферментов 특정 терпеноидных путей (например, каротиноидный путь через CRTI, CRTB, CRTY)
  * Использование синтетических промоторов и терминаторов для тонкой настройки экспрессии
- **Компартментализация**: Локализация терпеноидсинтаз в пероксисомах (через PTS1 сигналы) или митохондрии для повышения локальной концентрации субстратов и снижения метаболической нагрузки
- **Снижение конкурирующих путей**: Подавление эргостерола biosynthesis через downregulation ERG9 или использование мутантов ERG20 для перенаправления фарнезилпирофосфата (FPP) к желаемым терпеноидам
- **Повышение поставок предшественников**: Усиление ацетил-CoA пула через overexpression ACL (ATP-citrate lyase) или ACS (ацетил-CoA синтетаза), увеличение NADPH через пентозофосфатный путь
- **Экспрессионные системы**: Использование inducible промоторов (POX2, FBA1, hp4d) для временного контроля экспрессии терпеноидного пути
- **Геномические инструменты**: Применение CRISPR/Cas9 для точечной редакции генов и промоторной инженерии

## Рычаг повышения выхода
Для повышения производства терпеноидов в Y. lipolytica через метаболическую инженерию можно:
- **Генетические модификации**:
  * Overexpression ключевых ферментов MVA пути (особенно HMG1 и ERG20) с использованием сильных промоторов (TEF1, hp4d)
  * Инженирование ERG20 дляaltered продуктной специфичности (например, F296W мутант для смещения продукции к фарнезену)
  * Knockdown или knockout конкурирующих генов (ERG9 для эргостерола, PID1 для пубицетина)
  * Overexpression терпеноидспецифичных синтаз (например, лимонен-синтаза, каротиноидсинтазы)
- **Компартментализация**:
  * Добавление PTS1 сигналов к терпеноидсинтазам для пероксисомальной локализации
  * Оverexpression ферментов пероксисомального β-окисления для увеличения ацетил-CoA пула в пероксисомах
  * Целевая локализация в митохондрии для доступа к альтернативному пулу ацетил-CoA
- **Метаболические стратегии**:
  * Усиление производства NADPH через overexpression ZWF1 (глюкозо-6-фосфатдегидрогеназа) и GND1 (6-фосфоглюконатдегидрогеназа)
  * Повышение утилизации ацетил-CoA через overexpression ACS и ACL
  * Использование альтернативных источников углерода (например, гликозан, етанол) через метаболическую инженерию
- **Процессные подходы**:
  * Двухфазное культивирование: фаза роста (оптимизированная для биомассы) segued production фазы (оптимизированная для терпеноидов)
  * Fed-batch подача сахара или гликозана для поддержания высокого уровня ацетил-CoA и NADPH
  * Мониторинг уровня терпеноидов через in-line датчики или периодический отбор проб

## Открытые вопросы
- Какие конкретные гены из MVA пути показывают наибольший контроль над потоком терпеноидного biosynthesis в Y. lipolytica при разных условиях культивации?
- Как можно оптимизировать компартментализацию терпеноидсинтаз между пероксисомами, митохондриями и цитозолем для различных классов терпеноидов (монотерпеноиды, сесквитерпеноиды, дитерпеноиды)?
- Есть ли доказательства образования ферментомных комплексов (метابолинов) в терпеноидном пути Y. lipolytica, и как их можно усилить для повышения эффективности?
- Как pós-трансляционные модификации (фосфорилирование, убиквитинация) влияют на активность и стабильность ключевых терпеноидных ферментов в Y. lipolytica при высокой экспрессии?
- Какие стратегии можно использовать для преодоления токсичности высоких концентраций терпеноидов, особенно для летучих монотерпеноидов?

## Заметки
- Эта работа предоставляет систематизированный обзор стратегий метаболической инженерии для терпеноидного производства в Y. lipolytica, который можно непосредственно применять для оптимизации каннабиноидного пути (который также использует терпеноидный прекursor GPP).
- Стратегии, описанные в работе, такие как инженирование ERG20 для altered продуктной специфичности и компартментализация в пероксисомах, прямо применимы для каннабиноидного biosynthesis в Y. lipolytica (например, для улучшения продукции специфичных каннабиноидов через модификациюprenyltransferasы).
- Акцент работы на снижении конкурирующих путей (особенно эргостерола biosynthesis) важен для каннабиноидного пути, где конкуренция за GPP с эргостеролом может ограничивать титры каннабиноидов.
- Сочетание estratégій из этой работы с конкретными модификациями каннабиноидного пути (такие как overexpression OLS/OAC/CsPT4/THCAS и инженированиеprenyltransferasы) может привести к значительному повышению продуктивности в Y. lipolytica.
- Учитывая, что каннабиноидный biosynthesis требует両方 поликетидного (DVA) и терпеноидного (GPP) предшественников, стратегии по повышению производства терпеноидов из этой работы непосредственно применимы для увеличения GPP пула в каннабиноидном пути.
