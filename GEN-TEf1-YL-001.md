# TEF1 промотор - сила и регуляция в Yarrowia lipolytica

## Суть
TEF1 (транскрипционный фактор EF-1α) промотор является одним из самых сильных конститутивных промоторов в Yarrowia lipolytica, широко используемым для гетерологичной экспрессии ферментов каннабиноидного пути. Его высокая активность обеспечивает сильную транскрипцию целевых генов, что критично для превышения ферментативных bottleneck-ов в поликетидном и терпенильном синтезе.

## Детали
- **Последовательность**: TEF1 промотор в Y. lipolytica содержит консервативные элементы boxes, включая TATA-box и Inr (initiator), аналогичные S. cerevisiae TEF2 промотору
- **Сила**: Относительная сила промотора TEF1 в Y. lipolytica評估ваетsя как 2-5× сильнее промотора ADH1 и comparable с промотором hp4d
- **Регуляция**: TEF1 экспрессия конститутивна, но может быть умеренно подвержена catabolite репрессии при высокой глюкозе; менее чувствительна к азотному ограничению по сравнению с некоторыми stress-индуцированными промоторами
- **Интрон-содержащие варианты**: Теф-интрон promovторы (TEF-intron) показывают ещё более высокую экспрессию в Y. lipolytica за счет улучшенного сплайсинга и стабильности мРНК
- **Применение в каннабиноидном пути**: Используется для оверэкспрессии всех ключевых ферментов пути (OLS, OAC, CsPT4, THCAS, ACC1, ERG20) для повышения общего потока через путь
- **Ограничения**: При очень высокой экспрессии может привести к метаболическому бремени, накоплению неправильно свернутых белков и активации стресс-ответов

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через TEF1-promoter-mediated экспрессию можно:
- Съредовые:
  * Использование TEF-intron promovторов для максимальной экспрессии ключевых ферментов пути
  * Комбинирование TEF1 промотора с индуцируемыми системами для двухстадийного контроля (рост vs продуцирование)
  * Оптимизация копий числа гена через интеграцию в геном на несколько локусов для линейного увеличения экспрессии
  * Избегание очень высоких уровней глюкозы (>40 г/л) при экспрессии, чтобы снизить catabolite repression
  * Поддержание умеренного уровня азота для предотвращения стресс-ответов при высокой экспрессии
- Инженерные подходы:
  * Создание гибридных promovторов, объединяющих элементы TEF1 с другими сильными promuotрами (hp4d, POX2) для аддитивного эффекта
  * Экспрессия хелпер-белков (хэперонов, PDI) для улучшения сворачивания гетерологичных ферментов при высокой экспрессии
  * Модификация 5'UTR и 3'UTR областей для улучшения трансляции и стабильности мРНК
  * Использование codon-оптимизированных версий гетерологичных генов в сочетании с TEF1 промотором для синергетического эффекта
- Процессные:
  * Fed-batch стратегия с экспоненциальной подачей глюкозы для согласования высокой экспрессии с метаболической нагрузкой
  * Двухфазное культивирование: фаза роста при низкой продуктивной экспрессии, seguida production фазы при высокой TEF1-driven экспрессии
  * Мониторинг уровня метаболического бремени через измерение уровня unfolded protein response (UPR) маркеров

→ зависит от: доступности транскрипционного machinery и рибосом для высокой трансляции, уровня энергии (ATP) для синтеза белка и активности ферментов, уровня NADPH и ацетил-CoA для субстратных путей, [[GEN-002]] (сам по себе является примером TEF1-driven экспрессии ACC1), [[GEN-003]] (усиление MVA пути через TEF1-driven экспрессию ERG20), [[GEN-004]] (усиление пропионил-CoA пула через TEF1-driven экспрессию соответствующих лигаз), [[ADD-glycerol]] (источник ацетил-CoA и NADPH для поддержания высокой метаболической активности)
→ антагонизм с: метаболическим бременем при очень высокой экспрессии приводящим к снижению роста и продукта, конкуренцией за ресурсы трансляции и складки с endogenous белками, потенциальной активацией протеазного деградации при перегрузке секреторного пути

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по промоторной силе в S. cerevisiae и общих принципов экспрессии в Y. lipolytica из-за отсутствия прямых измерений для каннабиноидного пути.
- Требуется экспериментальная валидация силы TEF1 промотора для каждого ключевого ферментов каннабиноидного пути в Y. lipolytica и определение оптимального соотношения их экспрессии для максимального выхода THCVA.
- TEF1 промотор широко используется в метаболической инженерии Y. lipolytica для производства лимонной кислоты, ферментов липаз и других промышленных продуктов, подтверждая его высокую активность в этом организме.
- Интрон-содержащие варианты TEF1 promuotров (такие как XPR2 TEF intron promoter) показали повышенную экспрессию в Y. lipolytica и могут быть particularmente útil для токсичных или метаболически нагрузочных путей.
- При очень высокой экспрессии через сильные promuotры вроде TEF1 может наблюдаться протеолиз неправильно свернутых белков через ubiquitin-proteasome pathway, что может снижать общий выход активного фермента.
