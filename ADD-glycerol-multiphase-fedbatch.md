# Многофазная подача глицерина как стратегия fed-batch культивации для Yarrowia lipolytica

## Суть
Многофазная подача глицерина включает раздельное добавление глицерина на разных стадиях fed-batch процесса для оптимизации производства биомассы, NADPH и ацетил-CoA, что критично для синтеза каннабиноидов (THCVA, CBGVA, DVA) через обеспечение достаточного уровня предшественников и redox баланса.

## Детали
- **Механизм действия**: Глицерин метаболизируется в дигидроксиацетонфосфат (DHAP) и глицеральдегид-3-фосфат (G3P), которые входят в гликолиз и путь глюконеогенеза, обеспечивая ацетил-CoA через пируватдегидрогеназный комплекс и NADPH через глицерин-3-фосфат дегидрогеназу и пентозофосфатный путь. Многофазный подход позволяет сначала накапливать биомассу на ранних стадиях, затем переходить к production фазе с высоким уровнем NADPH и ацетил-CoA для вторичного метаболизма.
- **Фазы подачи**:
  * Фаза 1 (рост): Высокая подача глицерина для быстрого накопления биомассы
  * Фаза 2 (переход): Снижение подачи для подготовки к production
  * Фаза 3 (production): Поддержание умеренной подачи для снабжения ацетил-CoA и NADPH без избыточного роста
- **Концентрации**: типично 10-20 г/л глицерина на фазу, с общей подачей до 40-60 г/л на протяжении ферментации.
- **Время подачи**: Фазы могут быть основаны на потреблении субстрата, уровня биомассы (OD600) или времени после инокуляции (например, 0-24 ч рост, 24-48 ч переход, 48+ ч production).
- **Влияние на каннабиноидный путь**: Обеспечивает баланс ацетил-CoA (для малонил-CoA через ACC1 и изопrenoids через MVA путь) и NADPH (необходим для восстановительных шагов в терпеноидном пути и потенциально для некоторых шагов поликетидного синтеза).
- **Синергия**: Хорошо комбинируется с импульсной подачей глюкозы (для быстрого реагирования на изменения) и пропионатом (для C3 боковой цепи).

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через многофазную подачу глицерина в fed-batch можно:
- **Добавка в среду**:
  * Фаза роста: 15-20 г/л глицерина для быстрого накопления биомассы (0-24 ч)
  * Фаза перехода: 5-10 г/л глицерина для истощения избыточных питательных и подготовки к production (24-48 ч)
  * Фаза production: 10-15 г/л глицерина с контролем остаточной концентрации 2-5 г/л (48+ ч)
  * Комбинация с импульсной подачей пропионата (например, 2-5 г/л каждые 12 ч) в production фазе
- **Процессные подходы**:
  * Использовать онлайн-мониторинга OD600 и pH для определения переходов между фазами
  * Интегрировать с стратегиями DO-stat для обеспечения достаточного кислорода при высокой метаболической активности
  * Мониторить остаточный глицерин через ферментные тесты или HPLC для точной настройки подачи

## Заметки
- Данные из PMC11807037 показывают, что глицерин поддерживает значительно более высокую продукцию β-каротенa (202 мг/л) по сравнению с глюкозой (63.3 мг/г сухого вещества), указывая на преимущество глицерина для терпеноидного пути.
- Многофазный подход позволяет дифференцировать цели на разных стадиях: биомасса на ранних стадиях, предшественники и redox баланс на production стадии.
- Для каннабиноидного производства особенно важен баланс между ацетил-CoA supply для малонил-CoA и NADPH supply для терпеноидного пути, который глицерин может обеспечить одновременно.
