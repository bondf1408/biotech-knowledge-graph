# Пантотенат (Vitamin B5) как предшественник CoA для пулов ацил-CoA

## Суть
Пантотенат (витамин B5) является обязательным предшественником в биосинтезе кофермента А (CoA), который необходим для активации всех карбоновых кислот в виде ацил-CoA эстеров. В контексте каннабиноидного синтеза в Y. lipolytica, пантотенат критичен для формирования ключевых строительных блоков: ацетил-CoA (для MVA пути и конкурирующих путей), пропионил-CoA (стартер для DVA) и малонил-CoA (удлинитель для поликетидного пути). Дефицит пантотената ограничивает общий пул CoA и снижает доступность всех ацил-CoA предшественников.

## Детали
**Биохимическая роль CoA:**
- CoA состоит из пантотената, аденина и цистеамина через серию ферментативных реакций
- Ацил-CoA эстеры образуются путем соединения карбонильной группы кислоты с тиоловой группой CoA
- CoA служит активной формой для ацил-трансфераз, включая поликетидные синтазы (PKS) и лигазы
- Критически важен для: активации пропионата → пропионил-CoA (DVA путь), бутирата → бутирил-CoA, ацетата → ацетил-CoA, малоновой кислоты → малонил-CoA

**Пантотенат метаболизм в Y. lipolytica:**
- Y. lipolytica может использовать экзогенный пантотенат или синтезировать его де novo из альанина и пантетиновой кислоты
- Транспортеры пантотената в Y. lipolytica не хорошо изучены
- Ферменты пантотената киназы (PanK) и фосфопатотенатеилитрансферазы участвуют в CoA биосинтезе

**Влияние на каннабиноидный путь:**
- Достаточный пантотенат → увеличение общего пула CoA → повышенная доступность пропионил-CoA, ацетил-CoA и малонил-CoA
- Дефицит пантотената → ограничение CoA зависимых реакций → снижение продуцирования всех ацил-CoA → уменьшение выхода каннабиноидов
- Особенно критично для пропионил-CoA пула, который является лимитирующим фактором для DVA синтеза

## Рычаг повышения выхода
Для увеличения пулов ацил-CoA через пантотенат можно:
- Генетически:
  * Overexpression пантотената киназы (PanK) для увеличения фосфорилирования пантотената
  * Overexpression фосфопатотенатеилитрансферазы (PPT) дляCoA синтеза
  * Overexpression транспортеров пантотената для увеличения внутриклеточного пула
  * Инженерирование ферментов CoA биосинтеза с уменьшенной обратной связью ингибирования
- Средовые:
  * Добавка пантотената в концентрации 10-500 мкМ для обеспечения достаточного предшественника
  * Использование пантотената-содержащих добавок (дрожжевой экстракт) как естественного источника
  * Оптимизация времени добавки в conjunction с углеродными источниками
- Процессные:
  * Мониторинг общего пула CoA через анализ ацил-CoA эстеров
  * Комбинирование пантотената с биотином для синергетического эффекта на ACC1 и малонил-CoA
  * Использование пантотената в фазе produkcji для поддержания CoA зависимых реакций
