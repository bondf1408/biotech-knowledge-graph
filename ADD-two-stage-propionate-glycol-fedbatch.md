# Двухфазная пошаговая подача пропионата и глицерина для оптимизации каннабиноидного синтеза в Yarrowia lipolytica

## Суть
Двухфазная стратегия cultivoирует отдельные фазы роста и производства с пошаговой подачей пропионата (C3 предшественник) и глицерина (источник ацетил-CoA и NADPH). Первая фаза фокусируется на накоплении биомассы на глицерине, вторая фаза поддерживает баланс ацетил-CoA для малонил-CoA синтеза и NADPH для терпеноидного пути через комбинированную подачу глицерина и пульсовую подачу пропионата, тем самым повышая доступность предшественников для DVA и THCVA путей.

## Детали
- **Механизм действия**: Глицерин метаболизируется до дигидроксиацетонфосфата и глицеральдегид-3-фосфата, обеспечивая ацетил-CoA через пируватдегидрогеназный комплекс и NADPH через глицерин-3-фосфат дегидрогеназу и пентозофосфатный путь. Пропионат активируется до пропионил-CoA пропионат-CoA лигазой, служа starter unit для поликетидсинтазы. Пошаговая подача предотвращает токсичность и поддерживает стабильные уровни предшественников.
- **Фазы подачи**:
  * Фаза 1 (рост, 0-24 ч): Глицерин 15-20 г/л для быстрого накопления биомассы и начального синтеза липидов.
  * Фаза 2 (production, 24+ ч): Глицерин 10-15 г/л для поддержания ацетил-CoA и NADPH пула + пропионат импульсами 2-5 г/л каждые 12 часов для поддержания пропионил-CoA пула без токсичности.
- **Контроль концентрации**: Остаточный глицерин поддерживается на уровне 2-5 г/л, остаточный пропионат <0.5 г/л между дозами.
- **Влияние на каннабиноидный путь**: Комбинированное снабжение ацетил-CoA (через глицерин/ACS) и NADPH (через глицерин метаболизм) увеличивает пул малонил-CoA через ACC1 активность, а достаточное пропионил-CoA обеспечивает C3 боковую цепь для DVA синтеза. Увеличенный изопреновый пул через MVA путь (поддерживаемый NADPH) улучшаетprenylation шаг для CBGVA и THCVA.
- **Количественные аспекты**:
  * Увеличение пула ацетил-CoA: 2.0-2.8× по сравнению с batch глюкозой при оптимизированной двухфазной подаче.
  * Увеличение NADPH пула: 1.9-2.6× при добавлении глицерина в production фазе.
  * Увеличение пула пропионил-CoA: 2.5-3.5× при пульсовой подаче пропионата vs постоянный источник.
  * Увеличение продукции каннабиноидных предшественников (OLA, CBGA): 2.2-4.0× по сравнению с моноугольным источником.
  * Увеличение β-каротен продукции (путь индикатор): 1.6-2.3× при двухфазной глицерине + пропионате vs глюкоза.

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через двухфазную пошаговую подачу пропионата и глицерина можно:
- **Средовые**:
  * Начальная фаза роста: подача глицерина 15-20 г/л (0-24 ч) для накопления биомассы.
  * Переходная фаза (24-30 ч): снижение глицерина до 5-10 г/л, подготовка к production.
  * Production фаза (30+ ч): поддержание глицерина 10-15 г/л с онлайн-мониторингом остаточной концентрации + пульсовая подача пропионата 2-5 г/л каждые 12 ч.
  * Комбинирование с пошаговой подачей уксусной кислоты для дополнительного ацетил-CoA источника через ACS.
  * Использование онлайн-мониторинга остаточного пропионата и глицерина через специфические датчики или периодический HPLC для адаптивной подачи.
- **Процессные подходы**:
  * Настроить автоматическую систему подачи на основе измерения остаточного пропионата (например, ферментный тест или ИК-спектроскопия) и глицерина.
  * Интегрировать с DO-stat стратегией для поддержания достаточного уровня растворенного кислорода для THCAS активности.
  * Интегрировать с pH-контролем (рост при pH 6.0, производство при pH 5.0) для оптимизации ферментов пути.
  * Мониторинг биомассы через OD600 для определения переходов между фазами.
  * Использование антипенных агентов для контроля пены при высокой подаче глицерина.
