# Метаболическая инженерия Yarrowia lipolytica для синтеза изопрена

## Суть
Shaikh и Odaneth 2021 исследовали потенциал Y. lipolytica как носителя для синтеза изопрена, интегрировав один копийный ген IspS из Pueraria montana и усилив ключевые узлы MVA-пути.

## Ключевые параметры
- **Генетический ввод**:
  - Кодон-оптимизированный IspS из Pueraria montana, интегрированный в Y. lipolytica в одной копии.
- **Усиление пути**:
  - Первичная продукция была не обнаружена до оверэкспрессии HMGR / tHMGR.
  - Конечный конструкт включал оверэкспрессию HMGR (или tHMGR) вместе с Erg13 и IDI.
- **Производительность**:
  - Изопрен титры ~500 μg/L.
  - Отдача ~80 μg/g DCW.
- **Патофенотипы**:
  - Рекомбинантные штаммы демонстрировали повышенное содержание липидов и сквалена по сравнению с немодифицированным штаммом.

## Значение
- Отмечает критическую роль HMGR/tHMGR в переводе потока в DMAPP и последующий синтез изопрена.
- Подчеркивает, что Y. lipolytica является перспективным хостом для летучих половинок терпенов, несмотря на низкие стартовые титры.
