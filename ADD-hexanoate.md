# Гексановая кислота / гексанил-CoA как стартовая единица для синтеза оливетоловой кислоты и аналогов

## Суть
Гексановая кислота (C6) может быть активирована до гексанил-CoA и использована как стартовая единица для оливетол-синтазы (OLS) или тетракетид-синтазы (TKS) вместо пропионил-CoA, приводя к производству аналогов оливетоловой кислоты с удлиненной алкильной цепью. В контексте каннабиноидного biosynthesis, гексанил-CoA может приводить к производству гексаноил-каннабиноидов (например, гексагидроканнабиговой кислоты, HHGA) вместо дивариновой кислоты (DVA). Однако, при достаточном уровне экспрессии OLS с определенной специфичностью, гексанил-CoA также может использоваться для производства аналогов DVA с C5 боковой цепью, которые могут быть дальнейшими прекурсорами для гексанил-каннабиноидов.

## Детали
- **Механизм активации**: гексановая кислота активируется до гексанил-CoA через ацетил-CoA синтетазу (ACS) или ацил-CoA синтетазу с активностью по гексановой кислоте (например, FadD-подобные ферменты) в реакции: гексановая кислота + CoA + АТФ → гексанил-CoA + АДФ + Pi.
- **Специficность OLS**: типичная растительная OLS (например, из Cannabis sativa) показывает предпочтение к пропионил-CoA作为起始单元, но может принимать гексанил-CoA с меньшей эффективностью, продуцируя соответствующие поликетиды.
- **Длина цепи**: использование гексанил-CoA (C6) вместо пропионил-CoA (C3) увеличивает длину алкильной цепи конечного поликетида на три углерода, что может влиять на свойства конечного продукта.
- **Кофакторы**: требует CoA и АТФ для активации; для функционирования OLS/TKS необходимы малонил-CoA как удлинитель цепи.
- **Оптимальные условия активности**: pH optimum около 5.5–6.0 для многих ферментов жирного кислотного метаболизма в Y. lipolytica; температура 28–30°C типична.
- **Ожидаемый эффект**: 
  * При использовании как стартовой единицы для OLS: производство C9-β-кетокислот (например, аналогов оливетоловой кислоты с C6 боковой цепью) вместо обычных C6-продуктов (OLA).
  * В контексте каннабиноидного пути: потенциальное производство гексанил-каннабиноидных прекурсоров (например, CBGHA → THCHA) вместо CBGVA/THCVA.
  * При низкой специфичности OLS к гексанил-CoA: конкуренция за малонил-CoA и потенциальное подавление производства DVA.
- **Побочные пути**: окисление гексановой кислоты через β-окисление, интеграция в синтез сложных липидов, выделение в среду.

## Рычаг повышения выхода
Для увеличения выхода желаемых поликетидов через гексановую кислоту можно:
- Средовые:
  * Добавка гексановой кислоты в концентрации 0.1-2 г/л как потенциальной стартовой единицы
  * Использование в комбинации с пропионатом для изучения конкурентного включения starter units
  * Контроль pH и уровня растворенного кислорода для оптимальной активности ферментов
  * При необходимости подавления β-окисления: использование ингибиторов или knockout гена
- Процессные:
  * Мониторинг концентрации гексановой кислоты в среде (например, через GC-MS)
  * Измерение уровня активированного гексанил-CoA (например, через ферментативный анализ или изотопные метки)
  * Контроль уровня экспрессии гетерологичных конструктов каннабиноидного пути и OLS/TKS
  * Мониторинг производства специфических поликетидов (например, через HPLC-MS для идентификации цепочек разной длины)
  * Комбинирование с оверэкспрессией ключевых ферментов пути (например, ACC1 для малонил-CoA, OLS для поликетидного синтеза)
  * Инженерия OLS для altered специфичности к starter units (увеличение принятия гексанил-CoA)
