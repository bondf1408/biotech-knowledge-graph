# Эффективный синтез Geranylgeraniol (GGOH) в Yarrowia lipolytica

## Суть
Wang et al. 2024 построили Y. lipolytica для высокоэффективного синтеза GGOH, важного ароматического ди-терпена и предшественника витамина E.

## Ключевые параметры
- **Генетика**:
  - Экспрессия гетерологичных фосфатаз для высвобождения GGOH из GGPP.
  - Усиление образования FPP/GGPP через промоторную оптимизацию.
  - Снижение потока в путь сквалена за счёт угнетения генов путей прежнего типа.
- **Производительность**:
  - 3346.47 mg/L GGOH в тигле.
- **Сопутствующие меры**:
  - Оптимизация условий ферментации.
  - Снижение реактивных видов кислорода для повышения выхода.
- **Значение**:
  - Устанавливает новый ориентир по титру GGOH для Y. lipolytica.
  - Важен для направления к производству C20/C40 терпеновых производных.
