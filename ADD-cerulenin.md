# Церулений (cerulenin) как ингибитор синтеза жирных кислот для перенаправления малонил-CoA на поликетидный синтез

## Суть
Церулений ингибирует β-кетоацил-[белок-носитель] sintазу (KAS) в комплексе жирно-кислотной синтазы (FAS), блокируя синтез жирных кислот и перенаправляя пул малонил-CoA на поликетидный синтез. В Y. lipolytica, где липидный метаболизм доминирует, ингибирование FAS церулином может увеличить доступность малонил-CoA для поликетидсинтаз (OLS/OAC), тем самым повышая производство дивариновой кислоты (DVA) и связанных каннабиноидных предшественников.

## Детали
- **Механизм ингибирования**: церулений образует ковалентную связь с цистеиновым остатком в активном центре β-кетоацил-[ACP] синтазы (KAS) FAS, irreversibly инактивируя фермент.
- **Цель**: жирно-кислотная синтаза (FAS) комплекса, в частности β-кетоацил-[ACP] синтаза.
- **Кофакторы**: не требует кофакторов для своего действия (ингибирование происходит через прямой связывание с ферментом).
- **Оптимальные условия активности**: эффективен в широком диапазоне pH (5.0–8.0) и температур (20–37°C).
- **Ожидаемый эффект**: ингибирование FAS → снижение синтеза жирных кислот → накопление малонил-CoA → увеличение субстрата для поликетидсинтаз → рост титров поликетидов (OLA, DVA и аналогов).
- **Побочные пути**: потенциальная токсичность при высоких концентрациях из-за нарушения липидного метаболизма, необходимого для клеточных мембран.

## Рычаг повышения выхода
Для увеличения выхода поликетидов через церулин можно:
- Генетически: (не применимо напрямую, но можно рассмотреть штаммы с пониженной чувствительностью к церулину для длительного применения)
- Средовые:
  * Добавка церулина в концентрации 10-100 мкМ для ингибирования FAS без значительной токсичности
  * Использование пульсовой подачи (например, добавка каждые 12 часов) для поддержания ингибирования при снижении накопления токсичности
  * Комбинирование с добавками, снижающими окислительный стресс (например, глутатион) для компенсации потенциальных побочных эффектов
- Процессные:
  * Мониторинг уровня церулина через спектроскопические методы (ВЭЖ-Х, масс-спектрометрия)
  * Контроль уровня экспрессии гетерологичных конструктов через западноблоттинг или флюоресценцию
  * Измерение уровня синтеза жирных кислот (например, через окрашивание Oil Red O или GC-MS жирных кислот)
  * Мониторинг роста и viability клеток для избежания токсических эффектов
  * Комбинирование с оверэкспрессией ACC1 (GEN-002) для синергетического эффекта по увеличению пула малонил-CoA
