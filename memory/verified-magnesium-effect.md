Added verified experimental data from PMC12930956 showing that omitting MgSO4 from YNB-free mineral medium increases flaviolin (polyketide) titer from 0.43 g/L to 0.90 g/L (~2.09×) in Yarrowia lipolytica. Updated DATA-HEATMAP-001.md with these verified data points and MED-002.md to reflect both hypothetical and verified magnesium effects. Changed confidence descriptions to indicate some entries are now verified.

**Why:** This provides the first experimentally verified quantitative micronutrient claim in the knowledge base, moving beyond hypothesis/analog data to direct measurements in Y. lipolytica.

**How to apply:** Use this verified data point as anchor for refining analog models and hypothesis generation for other micronutrients. Update associated GEN cards (like GEN-ACC1-OE-YL-001) to reference this experimental validation of Mg2+'s role in ACC1 activity and malonyl-CoA availability.
