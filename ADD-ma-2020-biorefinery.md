# Синтетическая биология, системная биология и метаболическая инженерия Yarrowia lipolytica в направлении создания устойчивой биоперерабатывающей платформы

## Суть
Ma et al. 2020 демонстрируют комплексный подход к превращению Y. lipolytica в устойчивую биоперерабатывающую платформу через интеграцию синтетической биологии, системной биологии и метаболической инженерии. Работа рассматривает стратегии повышения производства липидов, терпеноидов и других ценных соединений через оптимизацию центрального метаболизма, снижение нагрузки на клетку и улучшение устойчивости к стрессу.

## Детали

### Ключевые стратегии для создания биоперерабатывающей платформы
1. **Оптимизация центрального метаболизма**: Повышение эффективности гликолиза и пентозофосфатного пути для увеличения снабжения предшественниками (ацетил-CoA, NADPH, ATP)
2. **Липидный метаболизм**: Усиление синтеза триацилглицеридов (TAG) через overexpression DGAT и снижение β-окисления для накопления липидов
3. **Терпеноидный путь**: Оптимизация MVA и MEP путей для производства ценных изопренов (стеролы, каротиноиды)
4. **Снижение метаболической нагрузки**: Подавление нежелательных путей (например, produkcия этиола, глицерина) через knockdown конкурирующих генов
5. **Стрессоустойчивость**: Повышение устойчивости к осмотическому, окислительному и температурному стрессу для поддержания продуктивности в промышленных условиях
6. **Комплементарные подходы**: Интеграция ферментативных каскадов, компартментализация пероксисом и митохондрий для повышения локальной концентрации ферментов и субстратов
7. **Динамическая регуляция**: Использование inducible промоторов и обратных связей для временного контроля экспрессии пути

### Генетические модификации, использованные в работе
- Overexpression DGAT (диацилглицерил-ацилтрансфераза) для повышения синтеза TAG
- Knockdown POX (пероксисомального β-окисления) для снижения распада жирных кислот
- Overexpression ферментов MVA пути (HMG1, ERG12, ERG20) для увеличения изопренового pool
- Overexpression генов pentose phosphate pathway (ZWF1, GND1) для увеличения NADPH
- Overexpression генов осмотической защиты (HSP12, SSA4) для стрессоустойчивости
- Интеграция пероксисомального сигнала PTS1 дляาลлокализации ключевых ферментов в пероксисомы
- Использование inducible промотора hp4d для временного контроля экспрессии

## Открытые вопросы
- Какие конкретные гены были модифицированы для достижения повышенного производства липидов и терпеноидов в Y. lipolytica и какова их относительная значимость?
- Требуется ли компартментализация ключевых ферментов каннабиноидного пути (OLS, OAC, CsPT4, THCAS) в определенные органеллы (пероксисомы, митохондрии) для максимальной эффективности в контексте биоперерабатывающей платформы?
- Как посттрансляционные модификации (фосфорилирование, ацетилирование) влияют на активность и стабильность инженерированных ферментов в условиях высокой экспрессии и стресса?
- Есть ли доказательства эпистатических взаимодействий между модифицированными генами, где комбинация определенных модификаций дает синергетический эффект превышающий сумму индивидуальных эффектов?
- Как оптимизировать соотношение производства липидов и терпеноидов для обеспечения достаточного пула предшественников (ацетил-CoA) для каннабиноидного пути без значительного снижения липидного продукта?

## Заметки
- Эта работа предоставляет системную основу для дальнейшей оптимизации каннабиноидного biosynthesis в Y. lipolytica,addressing ключевые ограничения, связанные с метаболической нагрузкой, доступностью предшественников и стрессоустойчивостью.
- Стратегии снижения конкурентных путей (например, подавление производства этиола и глицерина) могут быть непосредственно применены для повышения выхода каннабиноидных предшественников.
- Интеграция пероксисомальной локализации через сигналы PTS1 показывает promise для повышения локальной концентрации ацетил-CoA, что выгодно для поликетидсинтаз (OLS/OAC).
- Комбинация метаболической инженерии (повышение пулов предшественников), системной биологии (динамическая регуляция) и синтетической биологии (гетерологичные пути) представляет мощную платформу для производства сложных природных соединений в Y. lipolytica.
