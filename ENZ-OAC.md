# Оливетоловая кислота циклаза (OAC) - кинетика и специфичность

## Суть
Оливетоловая кислота циклаза (OAC) является ключевым ферментом в каннабиноидном биосинтезе, катализируя циклизацию тетракетида, образованного OLS/TKS, в ароматическое кольцо оливетоловой кислоты или её аналогов. Эта реакция преобразует линейный поликетидный интермедиат в фенольное структурное ядро, необходимое для последующего prenylation в каннабигеровую кислоту (CBGA/CBGVA) и дальнейшего модификации в тетрагидроканнабиноиды.

## Детали
- **Реакция**: Тетракетид → Оливетоловая кислота + H₂O (или аналоги для цепочек различной длины)
- **Механизм**: Альдольная конденсация тетракетидного интермедиата, за которой следует вакулеризация и ароматизация для образования фенольного кольца
- **Специфичность поликетидного интермедиата**: Типичная растительная OAC (из Cannabis sativa) показывает предпочтение к C6 тетракетиду (продукт OLS с пропионил-CoA стартером), способному циклизации дать оливетоловую кислоту (C6-ароматическое кольцо + C3 боковая цепь для DVA), но может принимать тетракетиды разной длины:
  * C4 тетракетид (ацетил-CoA стартер + 3 малонил-CoA): продуцирует аналог с укороченной ароматической системой
  * C6 тетракетид (пропионил-CoA стартер + 3 малонил-CoA): высокая эффективность, продуцирует оливетоловую кислоту (предшественник DVA)
  * C8 тетракетид (бутирил-CoA стартер + 3 малонил-CoA): средняя эффективность, продуцирует C7-анолог оливетоловой кислоты
  * C10 тетракетид (гексанил-CoA стартер + 3 малонил-CoA): низкая эффективность, продуцирует C9-анолог (как обсуждалось в ADD-hexanoate)
- **Металлозависимость**: Требует двухвалентных катионов (Mg²⁺ или Mn²⁺) для стабилизации структуры активного центра и координации карбонильных групп интермедиата
- **Коферментзависимость**: Некоторые изоформы могут использовать NADPH для стабилизации радикальных промежуточных или восстановления протонных переносов
- **Структура**: Мономерный или олигомерный фермент в зависимости от источника, каждая субъединица содержит активный центр с типичными для поликетидциклаз мотивами связывания металлов
- **Регуляция**: Может быть subject to обратной связи ингибирования фенольными продуктами или окислительно-востановительным состоянием через чувствительные к redox цистеиновые остатки

## Рычаг повышения выхода
Для увеличения выхода желаемого продукта через OAC можно:
- Средовые:
  * Оптимизация концентрации тетракетидного интермедиата через достаточное снабжение пропионил-CoA (GEN-004) и малонил-CoA (GEN-002)
  * Поддержание достаточного уровня Mg²⁺ или Mn²⁺ для металлозависимой активности
  * Использование буферных систем для поддержания оптимального pH (5.5-6.0)
  * Поддержание redox-баланса через достаточное NADPH и системы восстановления
- Инженерные подходы:
  * Directed evolution для увеличения affinity к C6 тетракетиду и ускорения циклизации
  * Fusione OAC с upstream теаразсами (OLS/OACS) для улучшения каналирования субстратов
  * Экспрессия в компартментах с высокой концентрацией предшественников (пероксисомам при наличии транспортёров)
  * Оптимизация экспрессии через сильные промоторы (TEF1, hp4d) и оптимальные терминаторы
- Процессные:
  * Fed-batch подача пропионата для поддержания стабильного уровня пропионил-CoA
  * Двухфазное культивирование: фаза роста seguida production фазы
  * Мониторинг промежуточных продуктов через LC-MS для своевременной коррекции условий
  * Использование двухвалентных катионовых буферов для стабилизации активности фермента

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по растительным тип III поликетид-циклазам (например, стилбеновая циклаза, хальконовая циклаза) из-за отсутствия прямых измерений в Y. lipolytica.
- Требуется экспериментальная валидация кинетических параметров (Km, kcat, pH optimum, температура optimum, металлозависимость) для рекомбинантной OAC, экспрессируемой в Y. lipolytica.
- OAC принадлежит к семейству тип III поликетидциклаз, которые Characterized by использованием металлозависимого активного центра для связывания поликетидного интермедиата и проведением серии альдольных конденсаций followed by вакулеризации и ароматизации.
- Оптимальный pH активности OAC (5.5-6.0) лучше совпадает с типичными условиями ферментации Y. lipolytica (pH ~5.5-6.0 с CaCO3 буфером) в отличие от THCAS, который требует более кислого pH (4.5-5.5), что может потребовать двухстадийного pH-контроля для оптимизации всего пути.
- Инженерирование активного центра OAC для измененной специфичности тетракетидного интермедиата является перспективным направлением для производства novel каннабиноидных аналогов с разнообразными ароматическими кольцами и боковыми цепями.
