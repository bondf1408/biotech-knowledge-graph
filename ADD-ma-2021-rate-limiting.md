# Преодоление ограничивающих этапов в биосинтезе предшественника каннабиноидов оливетоловой кислоты

## Суть
Ma et al. 2021 bioRxiv препринт демонстрирует 83-кратное увеличение производства оливетоловой кислоты (OLA) - ключевого предшественника каннабиноидов - в генетически инженерированной Yarrowia lipolytica путем преодоления ограничивающих этапов в пути синтеза. Работа probablemente описывает конкретные гены и промоторы для повышения экспрессии ферментов пути и перераспределения углеродного потока в сторону производства OLA и downstream каннабиноидов.

## Детали

### Ключевые находки
- **83-кратное увеличение OLA**: Удаление ограничивающих этапов приводит к значительному повышению продукции предшественника каннабиноидов
- **Генетические модификации**: Вероятно включает overexpression ключевых ферментов пути (OLS, OAC) и/или downregulation конкурирующих путей
- **Инженерия промоторов**: Использование сильных промоторов (TEF1, hp4d и т.д.) для повышения экспрессии ограничивающих ферментов
- **Перераспределение углеродного потока**: Модификация метаболических потоков для увеличения снабжения предшественников (ацетил-CoA, малонил-CoA, пропионил-CoA) для OLS
- **Снижение обратной связи ингибирования**: Возможная модификация для уменьшения влияния продуктов пути на активность upstream ферментов

### Ограничивающие этапы в пути каннабиноидов
1. **Оливетол-синтаза (OLS)**: Теракетид-синтаза, часто ограничивающая начальный этап поликетид синтеза
2. **Малонил-CoA снабжение**: Доступность малонил-CoA для удлинения цепи в OLS реакции
3. **Ацетил-CoA стартерная единица**: Доступность пропионил-CoA для C3 боковой цепи в DVA-пути (или ацетил-CoA для OLA пути)
4. **Оливетоловая кислота циклаза (OAC)**: Циклизация тетракетида в ароматическое кольцо
5. **Каннабигеролпрегненилтрансфераза (CsPT4)**: Пренятивание OLA/OA для производства CBGA/CBGVA
6. **THCA синтаза (THCAS)**: Окислительно-циклизирующее преобразование в финальные каннабиноиды

### Генетические стратегии для преодоления ограничений
- **Overexpression ферментов пути**: Увеличение экспрессии OLS, OAC и downstream ферментов
- **Промоторная инженерия**: Замена естественных промоторов на сильные конститутивные (TEF1, hp4d) или inducible системы
- **Кодонная оптимизация**: Адаптация генов под кодонные предпочтения Y. lipolytica для повышения трансляционной эффективности
- **Сегментация и локализация**: Направленная экспрессия ферментов в оптимальные компартменты (цитозоль, пероксисомы) для доступа к субстратам и кофакторам
- **Feedback-инсенситивные мутанты**: Инженерирование ферментов для резистентности к ингибированию продуктами пути

### Метаболические стратегии
- **Увеличение пула предшественников**: Повышение производства ацетил-CoA, малонил-CoA и пропионил-CoA
- **Балансировка кофакторов**: Обеспечение достаточного уровня FAD, NADPH, биотина и Mg²⁺ для активности ферментов
- **Снижение конкурирующих путей**: Downregulation синтеза жирных кислот и других конкурентов за ацетил-CoA
- **Оптимизация pH и температуры**: Настройка условий для максимальной активности ключевых ферментов пути

## Рычаг повышения выхода
Для преодоления ограничивающих этапов в каннабиноидном синтезе можно:
- Генетически:
  * Overexpression OLS с сильными промоторами (TEF1, hp4d) для увеличения тетракетид синтеза
  * Overexpression OAC для повышения эффективности циклизации тетракетида
  * Overexpression CsPT4 для увеличения прегненилирования OLA/OA
  * Overexpression THCAS для повышения конечного превращения в психоактивные каннабиноиды
  * Инженерирование промоторных регионов для тканеспецифической или inducible экспрессии
  * Коэкспрессия ферментов upstream пути (ацетил-CoA карбоксилаза, малонCoA синтетаза) для увеличения пула предшественников
  * Экспрессия feedback-инсенситивных вариантов ключевых ферментов пути
  * Использование синтетических биологических подходов (саключевые гены, рибосвитчи) для динамической регуляции
- Средовые:
  * Оптимизация концентрации гликозы как основного источника углерода и энергии
  * Регулирование уровня азота для влияния на вторичный метаболизм vs рост
  * Добавка предшественников (пропионат, ацетат, гликолят) для прямого увеличения пулов CoA derivатов
  * Модуляция pH (4.5-6.0 в зависимости от фермента) для оптимизации активности ключевых étapes
  * Оптимизация температуры (28-30°C) для баланса роста и продукции
  * Контроль уровня растворенного кислорода для поддержания активности THCAS и других оксидаз
- Процессные:
  * Fed-batch стратегии с импульсной подачей предшественников на разных фазах роста
  * Двухфазное культивирование: фаза роста на оптимизированной среде для биомассы, фаза производства на среде для maksymalnej produkcji metabolitów wtórnych
  * Непрерывное культивирование с продувочкой для стабильного длительного производства
  * Использование систем удаления продукта in situ (ISPR) для снижения продуктовой ингибирования

## Заметки
- [INFERRED]: Многие параметры экстраполированы из описания 83-кратного увеличения в Ma et al. 2021 и данных по метаболической инженерии каннабиноидных путей в других организмах из-за отсутствия прямых измерений в этой конкретной работе.
- Требуется экспериментальная валидация конкретных генетических модификаций, приведших к 83-кратному увеличению, для воспроизведения и дальнейшей оптимизации результата в Y. lipolytica.
- Стратегия преодоления ограничивающих этапов представляет собой основной подход в метаболической инженерии для увеличения продукции целевых метаболитов, особенно уместный для сложных многокомпонентных путей как каннабиноидный biosynthез.
- Комбинация генетических модификаций (промоторная инженерия, кодонная оптимизация, ферментная инженерия) с метаболическими стратегиями (увеличение пулов предшественников, балансировка кофакторов, downregulation конкурирующих путей) может дать синергетический эффект на производство каннабиноидов превышающий эффект каждого подхода по отдельности.
