# Малонат как предшественник малонил-CoA для удлинения цепи в поликетидном синтезе

## Суть
Малонат является внешним источником малаоновой кислоты, которая может быть активирована до малонил-CoA (хотя в основном малонил-CoA синтезируется из ацетил-CoA через ацетил-CoA карбоксилазу ACC1). Добавка малоната может увеличивать пул малонил-CoA за счет прямого вхождения в пул или через метаболические преобразования, тем самым повышая субстратную доступность для удлинения цепи в поликетидсинтазах (OLS/OAC) при производстве дивариновой кислоты (DVA) и связанных каннабиноидных предшественников.

## Детали
- **Ген**: хотя малонат сам по себе не требует специфичного гена для активации, его метаболизм может включать ферменты, такие как малонатдегидрогеназа или ацетил-CoA синтетаза с активностью по малонату. Основной путь увеличения малонил-CoA пула остается через оверэкспрессию ACC1 (GEN-002).
- **Модификация**: overexpression ферментов, участвующих в метаболизме малоната (например, малонатдегидрогеназа) под символичными промоторами TEF1 или hp4d, терминатор XPR2, вектор pYLXP' или интеграция в геном.
- **Кофакторы**: для активации малоната до малонил-CoA требуется CoA и АТФ (реакция: малонат + CoA + АТФ → малонил-CoA + АДФ + Pi), аналогично ацил-CoA синтетазе.
- **Оптимальные условия активности**: pH optimum около 7.0–7.5 для многих ацил-CoA лигаз; в ферментациях Y. lipolytica обычно используется pH-контроль CaCO3 для поддержания pH ~5.5–6.0.
- **Ожидаемый эффект**: увеличение пула малонил-CoA → повышение активности OLS/OAC → рост титров поликетидов (OLA, DVA и аналогов). Добавка малоната может компенсировать ограничения в синтезе малонил-CoA через ACC1.
- **Побочные пути**: конкуренция за CoA с синтезом ацетил-CoA и пропионил-CoA; потенциальная ингибиция высокими концентрациями малоната (обратная связь на ACC1?).

## Рычаг повышения выхода
Для увеличения уровня малонил-CoA через малонат можно:
- Генетически:
  * Overexpression малат- или малонат-дегидрогеназ для преобразования малоната в метаболиты, входящие в пул ацетил-CoA/малонил-CoA
  * Overexpression ацетил-CoA синтетазы (ACS) с активностью по малонату для прямой активации до малонил-CoA
  * Усилить экспрессию ACC1 (GEN-002) для повышения базового синтеза малонил-CoA из ацетил-CoA
- Средовые:
  * Добавка малоната (например, sodium malonate или malonic acid) в концентрации 0.1-5 г/л (~1.2-58 мМ) для обеспечения субстрата без токсичности
  * Использование хелатных агентов, улучшающих bioavailability малоната (например, цитрат в низких концентрациях)
  * Избегать сильных хелатентов (например, фитатов) в среде при работе с гетерологичной экспрессией
- Процессные:
  * Мониторинг уровня малоната через спектроскопические методы (ИК-спектроскопия, NMR)
  * Контроль уровня экспрессии гетерологичных конструктов через западноблоттинг или флюоресценцию
  * Комбинирование с другими добавками (например, магний для ACC1, цинк для транскрипции) для поддержания общего метаболического баланса
  * Использование буферных систем, минимизирующих осаждение при рабочем pH
