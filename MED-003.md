# Влияние pH на каннабиноидный биосинтез в Yarrowia lipolytica

## Суть
Разные ферменты каннабиноидного пути имеют различный pH-оптимум, что создает проблему для одновременной оптимизации всех шагов пути. Особенно критично отличие pH-оптимума THCAS (4.5–5.5) от типичного pH ферментации Y. lipolytica (5.5–6.0 с CaCO3 буфером). Это может требовать двухстадийного pH-контроля: сначала рост при оптимальном pH для биомассы, затем снижение pH для производства THCVA и других конечных продуктов.

## Детали
- **THCAS (THCA синтаза)**: Оптимальный pH 4.5–5.5 (см. ENZ-THCS), FAD-зависимая оксидоредуктаза, катализирующая окислительно-циклизирующее превращение CBGVA → THCVA
- **OAC (оливетоловая кислота циклаза)**: Оптимальный pH 5.5–6.0 (см. ENZ-OAC), Mg²⁺/Mn²⁺-зависимая циклаза, катализирующая превращение тетракетида → оливетоловая кисотa
- **CsPT4 (ароматический фенилпренилтрансфераза)**: Оптимальный pH 5.5–6.5 (см. ENZ-CsPT4), мембранно-ассоциированная prenyltransferase, катализирующая CBGA/CBGVA синтез
- **OLS (оливетол-синтаза/тетракетид-синтаза)**: Оптимальный pH 5.5–6.5 (см. ENZ-OLS), тип III поликетидсинтаза, катализирующая kondensaciya пропионил-CoA + малонил-CoA → тетракетид
- **ACC1 (ацетил-CoA карбоксилаза)**: Оптимальный pH 6.0–7.0 (см. ENZ-ACC1), биотин-зависимая карбоксилаза, производящая малонил-CoA из ацетил-CoA
- **ERG20 (GPP/FPP синтаза)**: Оптимальный pH 7.0–8.0 (см. ENZ-ERG20), Mg²⁺-зависимая prenyltransferase, производящая изопреновые доноры
- **Общий pH ферментации Y. lipolytica**: Обычно поддерживается на уровне 5.5–6.0 с использованием CaCO3 буфера для стабилизации при высокой загрузке глюкозой
- **Влияние pH на стабильность ферментов**: Некоторые ферменты могут денатурировать или терять активность при длительном экспозировании вне их оптимального pH диапазона
- **Влияние pH на транспортировку и проницаемость мембран**: Может влиять на поглощение субстратов и выделение продуктов
- **Двухстадийный pH-контроль**: Стратегия, при которой фаза роста биомассы происходит при оптимальном pH для роста (~5.5–6.0), а фаза производства продукта — при оптимальном pH для ключевых ферментов пути (особенно THCAS при 4.5–5.5)

## Рычаг повышения выхода
Для оптимизации pH для каннабиноидного производства можно:
- Среды:
  * Использование двухстадийного pH-контроля: рост при pH 5.5–6.0 (оптимальный для биомассы), затем снижение до pH 4.5–5.5 для производства THCVA
  * Буферизация среды слабыми буферами с pKa в диапазоне 4.5–5.5 (например, ацетат-буфера, фосфат-буфера с регулировкой)
  * Контролируемое добавление кислоты (лимонной, уксусной) или основания (NaOH, KOH, CaCO3) для поддержания целевого pH
  * Использование ионообменных смол или мембран для pH-контроля без добавления ионов, которые могут ингибировать ферменты
  * Выбор углеродных источников с минимальным acidifying эффектом (например, глюкоза предпочтительнее глицерина для меньшего production органических кислот)
- Инженерные подходы:
  * Экспрессия pH-стойких вариантов ферментов через directed evolution или рациональный дизайн (особенно для THCAS)
  * Экспрессия протонных насосов или антипортеров для улучшения pH-гомеостаза в клетке
  * Локализация pH-чувствительных ферментов в компартментах с буферизированным pH (например, периплазм
  * Создание синтетических микрокомпартментов или везикул с внутренним pH, оптимальным для конкретных ферментов
- Процессные:
  * Регулярный мониторинг pH в реальном времени с автоматическим добавлением кислоты/основания
  * Использование пены-разрушителей для предотвращения потерь продукта при pH-контроле
  * Поддержание постоянного ионическогоStrength при добавлении кислоты/основания для минимизации осмотического стресса
  * Оптимизация времени переключения между фазами роста и производства на основе on-line измерений биомассы и продуктов

→ зависит от: способности поддерживать стабильный pH в ферментере, доступности pH-контролирующих реагентов (кислоты/основания), буферной емкости среды, способности поддерживать стабильную температуру в ферментере, [[PRO-001]] (параметры процесса для pH- и температурного контроля)
→ антагонизм с: ростом биомассы при низком pH (<4.5 может подавлять рост), активностью ферментов оптимальных при более высоком pH (OAC, CsPT4, OLS, ACC1, ERG20 при pH >5.5), температурной нестабильностью, которая может денатурировать ферменты пути, конкурирующими путями, которые могут быть предпочтительны при определенных pH и температуре

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по растительным и грибковым аналогам ферментов из-за отсутствия прямых измерений в Y. lipolytica.
- Требуется экспериментальная валидация pH-оптимума и pH-стабильности для всех ключевых ферментов пути (THCAS, OAC, CsPT4, OLS, ACC1, ERG20) в Y. lipolytica.
- Учитывая, что оптимальный pH активности THCAS (4.5-5.5) значительно ниже типичного pH ферментации Y. lipolytica (5.5-6.0 с CaCO3 буфером), двухстадийный pH-контроль может значительно улучшить выход THCVA за счет разделения оптимизации роста и производства.
- Стратегия двухстадийного pH-контроля аналогична используемой для производства лимонной кислоты в Aspergillus niger, где pH снижается после фазы роста для подавления конкурирующих путей и стимулирования продукции продукта.
- pH может влиять не только на активность ферментов, но и на их экспрессию, стабильность, локализацию и взаимодействие с другими белками в пути.
