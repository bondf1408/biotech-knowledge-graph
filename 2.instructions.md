# РУКОВОДСТВО: База знаний по биосинтезу DVA / THCVA

## 1. Как работать с базой файлов

### 1.1 Создание новой карточки

**Когда создавать новую карточку:**
- Обнаружен новый ген / фермент / штамм / условие, которого ещё нет в базе
- Найдена публикация с количественными данными по уже существующей теме → обновляй имеющуюся карточку, НЕ создавай новую
- Новый тип объекта (новый организм-продуцент, новый путь синтеза)

**Именование файла:**
```
[ТИП]-[КРАТКОЕ_ОПИСАНИЕ].md
```
| Тип | Префикс | Пример |
|-----|---------|--------|
| Ген / генная модификация | GEN | GEN-propionyl-CoA-ligase.md |
| Соединение | CMP | CMP-004.md |
| Путь синтеза | PWY | PWY-0005.md |
| Фермент (детальная кинетика) | ENZ | ENZ-OLS.md |
| Среда культивирования | MED | MED-003.md |
| Параметры процесса | PRO | PRO-002.md |
| Организм-продуцент | ORG | ORG-005.md |
| Штамм | STR | STR-003.md |
| Взаимодействие | INT | INT-002.md |
| Плазмида / вектор | PLS | PLS-002.md |
| Добавка / кофактор | ADD | ADD-001.md |

**Обязательный YAML-фронтматтер:**
```yaml
---
id: [ТИП]-[ID]
type: [gene_modification / compound / pathway / enzyme / medium / process / organism / strain / interaction / reference]
organism: [yarrowia_lipolytica / s_cerevisiae / e_coli / p_pastoris / general]
target_compound: [THCVA / CBGVA / DVA / general]
pathway: [название пути или список путей]
tags: [тег1, тег2, тег3]
source_doi: [DOI или список DOI]
source_pmid: [PMID]
confidence: [high / medium / low]
date_added: [ГГГГ-ММ-ДД]
last_updated: [ГГГГ-ММ-ДД]
related_cards: [ID1, ID2, ID3]
---
```

**Правила confidence:**
- `high` — данные из рецензируемой статьи, прямой эксперимент
- `medium` — косвенные данные, аналогия с похожим ферментом/системой
- `low` — гипотеза, экстраполяция, не подтверждено

### 1.2 Обновление существующей карточки

**Когда обновлять:**
- Найдены новые количественные данные по тому же объекту
- Появилась новая публикация с уточнёнными кинетическими параметрами
- Изменился статус (гипотеза подтверждена / опровергнута)

**Порядок обновления:**
1. Открой файл карточки
2. Измени `last_updated` на сегодняшнюю дату
3. Добавь данные в раздел **Количественные данные** (не удаляй старые — они важны для сравнения)
4. Обнови `source_doi` если добавляешь новый источник
5. Измени `confidence` если данные стали более надёжными
6. Добавь новый `source_doi` к списку если это новая статья
7. После обновления файла → запусти `notion_fix.py` для синхронизации с Notion

**Синхронизация с Notion:**
```powershell
# После создания новых карточек — запусти импорт:
python notion_import.py   # добавит новые страницы (существующие не задублирует)

# После обновления существующих карточек:
python notion_fix.py      # обновит метаданные всех страниц
```

### БЛОК 5 — Кофакторы и их влияние на ключевые ферменты пути DVA/THCVA

Это критический и **слабо изученный** блок. Создай карточки типа [ADD] или [GEN] для каждого кофактора.

#### 5.1 Биотин (Vitamin B7) → ACC1 → малонил-CoA

Биотин — кофактор ацетил-CoA карбоксилазы (ACC1), которая производит малонил-CoA из ацетил-CoA. Малонил-CoA — строительный блок для DVA и всего поликетидного синтеза.

Поисковые запросы:
```
"biotin ACC1 acetyl-CoA carboxylase malonyl-CoA yeast"
"biotin supplementation polyketide production yeast"
"biotin deficiency malonyl-CoA Yarrowia lipolytica"
"biotin concentration ACC1 activity kinetics"
"biotin carboxylase Km yeast overexpression"
```

Ключевые вопросы для карточки:
- Какова концентрация биотина в стандартной среде для Y. lipolytica?
- Как дополнение биотина влияет на активность ACC1 и пул малонил-CoA?
- При какой концентрации биотина активность ACC1 насыщается?

---

#### 5.2 Пантотенат (Vitamin B5) → CoA → пул ацил-CoA

Пантотенат — предшественник кофермента А (CoA). Без CoA невозможен ни пропионил-CoA, ни бутирил-CoA, ни малонил-CoA. Критичен для всего поликетидного синтеза.

THCA-синтаза (THCAS) — FAD-зависимая оксидоредуктаза. Катализирует окислительную циклизацию CBGVA → THCVA. FAD необходим для её активности. Рибофлавин — предшественник FAD.
