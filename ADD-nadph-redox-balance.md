# НАДФН (NADPH) как кофактор для redox-баланса и регенерации FAD в синтезе каннабиноидов

## Суть
NADPH является Essential кофактором для множества окислительно-восстановительных реакций в Y. lipolytica, включая синтез жирных кислот (прекурсоры ацетил-CoA и малонил-CoA), регенерацию FAD в THCA-синтазе (THCAS) и активность NADPH-зависимых редуктаз. Перекос в соотношении NADPH/NADP⁺ является частым bottleneck в Y. lipolytica при производстве вторичных метаболитов, ограничивая доступность восстановленного кофактора для ключевых шагов пути каннабиноидов.

## Детали
**Роль NADPH в конкретных процессах:**
- **Синтез жирных кислот и активация ацетил-CoA**: NADPH необходим для фермента ацетил-CoA карбоксилазы (ACC1) в синтезе малонил-CoA из ацетил-CoA (хотя основной кофактор ACC1 — биотин, сам путь requiere NADPH для предоставления восстановленного ацетил-CoA пула через липогенез). Фактически, синтез жирных кислот потребует NADPH для стадии восстановления (например, энол-редуктаза, кето-редуктаза).
- **Регенерация FAD в THCAS**: THCA-синтаза (THCAS) использует FAD как кофактор, который восстанавливается до FADH₂ во время оксидоциклизации CBGVA → THCVA. Реокисление FADH₂ обратно в FAD может осуществляться через NADPH-зависимые редуктазы или напрямую через O₂, но в гетерологичной системе регенерация через NADH/NADPH пути может быть преимущественной.
- **Активность NADPH-зависимых редуктаз**: Некоторые ферменты в терпеноидном и поликетидном путях могут требовать NADPH для реакций восстановления (например, гранат-редуктаза, определенные терпен-редуктазы).
- **Антиоксидантная защита**: NADPH поддерживает уровень восстановленного глутатиона (GSH) через глютатионредуктазу, защищая клетку от окислительного стресса, который может возникать при высокой активности оксидаз (например, THCAS производящего H₂O₂).
- **Генерирование предшественников**: Через пентозофосфатный путь (PPP) глюкоза-6-фосфат дегидрогеназа (G6PDH) генерирует NADPH, одновременно обеспечивая рибозо-5-фосфат для нуклеотидов и предшественников для ароматического пути (который может конкурировать с каннабиноидным путем за фосфоэнонилпируват).

**Метаболизм NADPH в Y. lipolytica:**
- Y. lipolytica генерирует NADPH через несколько путей: пентозофосфатный путь (главный источник), малатный фермент, изоцитратдегидрогеназа (в митохондриях), и ферменты связанные с пероксисомами.
- Соотношение NADPH/NADP⁺ цитоплазматическое критично для восстановленного состояния клетки.
- Избыток NADPH может указывать на перенасыщение восстановительными эквивалентами, тогда как дефицит ограничивает восстановленные реакции.
- Трансгидрогеназа может балансировать NADH и NADPH пулы.

**Влияние на каннабиноидный путь:**
- Достаточный NADPH → достаточный пул малонил-CoA (через липогенез и ACC1), эффективная регенерация FAD в THCAS, активность восстановления-зависимых ферментов → повышенный выход через весь путь
- Дефицит NADPH → ограничение синтеза жирных кислот и малонил-CoA пула, нарушение регенерации FAD → накопление CBGVA и снижение продукции THCVA, снижение общего липидного метаболизма и preкурсоров
- Особенно критично для последнего шага (THCAS) где требуется цикл окисления-восстановления FAD и для обеспечения малонил-CoA пула для поликетидного синтеза

## Рычаг повышения выхода
Для увеличения уровня NADPH можно:
- Генетически:
  * Overexpression глюкозо-6-фосфат дегидрогеназы (ZWF1 гомолог) для усиления пентозофосфатного пути
  * Overexpression малатного фермента (например, Mae1p гомолог) для генерации NADPH из малата
  * Overexpression изоцитратдегидрогеназы (IDP1/IDP2 гомологи) в митохондриях
  * Uдалить или понизить экспрессию конкурентов за глюкозо-6-фосфат (например, глюкозо-6-фосфатáza в гликолизе) при условии перенаправления flux в PPP
  * Инженерирование трансгидрогеназы для улучшенного перевода między NADH и NADPH пулами
- Средовые:
  * Добавка глюкозы или глицерина как источника углерода для стимуляции PPP и липогенеза
  * Использование substrates, предпочтительно метаболизирующихся через PPP (например, рибоза, ксилоза)
  * Контроль pH и уровня растворенного кислорода для оптимальной активности ферментов-generating NADPH
  * Добавка буферных систем, поддерживающих redox-баланс (например, глиутшатион в низких концентрациях)
- Процессные:
  * Мониторинг уровня NADPH/NADP⁺ через ферментативные анализы или флуоресцентные датчики
  * Регулирование стратегии подачи субстрата: высокий глицерин может стимулировать глиниеNeogenesis и NADPH генерацию
  * Использование стрессовых условий, известных по увеличению PPP flux (например, легкий осмотический стресс)
  * Комбинирование с добавками, улучшающими доступность предшественников (ацетат, пропионат) для субстратного баланса
