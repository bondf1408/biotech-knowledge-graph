# Бутират как предшественник бутирил-CoA для синтеза поликетидов с C4-стартером

## Суть
Бутират является внешним источником масляной кислоты, которая активируется до бутирил-CoA бутирату-CoA лигазой (например, продуктом гена, homologous to ACSL). Бутирил-CoA служит starter unit (C4) для поликетидсинтазы (OLS/TKS) в синтезе поликетидов, отличных от DVA и OLA (например, hexанойл-CoA производные или другие боковые цепи). Достаточное снабжение бутиратом и эффективная его активация увеличивают пул бутирил-CoA, тем самым повышая субстратную доступность для альтернативных поликетидных путей.

## Детали
- **Ген**: бутирату-CoA лигаза (например, продукт гена, аналог фазной лигазы из Y. lipolytica или гетерологичная экспрессия из других организмов); возможно, та же лигаза, что и для пропионата (ACSL), но с различной специфичностью.
- **Модификация**: overexpression бутирату-CoA лигазы под сильными конститутивными промоторами TEF1 или hp4d, терминатор XPR2, вектор pYLXP' или интеграция в геном (например, в locus ku70 или YALI0C05907g locus).
- **Кофакторы**: требует АТФ и CoA для активации бутирата до бутирил-CoA (реакция: бутират + CoA + АТФ → бутирил-CoA + АДФ + Pi).
- **Оптимальные условия активности**: pH optimum около 7.0–7.5 для многих ацил-CoA лигаз; в ферментациях Y. lipolytica обычно используется pH-контроль CaCO3 для поддержания pH ~5.5–6.0, что может субоптимально для лигазы но компенсируется высокой экспрессией.
- **Ожидаемый эффект**: увеличение пула бутирил-CoA → повышение активности OLS/OAC с бутил-стартером → рост титров C4-поликетидов (например, 3-алкил-6-алкилрезорцинов или аналоги). При комбинации с оверэкспрессией ACC1 и достаточностью малонил-CoA возможен синтез новых поликетидных структур.
- **Побочные пути**: конкуренция за CoA с синтезом ацетил-CoA и малонил-CoA; потенциальная ингибиция высокими концентрациями бутирата (токсичность).

## Рычаг повышения выхода
Для увеличения уровня бутирил-CoA можно:
- Генетически:
  * Overexpression бутирату-CoA лигазы (возможно, той же ACSL, что и для пропионата, или отдельный ген) для увеличения активации бутирата
  * Overexpression ацетил-CoA синтетазы (ACS) для увеличения пула ацетил-CoA, который может быть преобразован в бутирил-CoA через метаболизм (менее прямой путь)
  * Удалить или понизить экспрессию конкурирующих путей ацетил-CoA (например, изменение регуляции PDC или ACS) для увеличения доступности ацетил-CoA для синтеза бутирил-CoA
- Средовые:
  * Добавка бутирата (например, sodium butyrate) в концентрации 0.1-5 г/л (~1.4-68 мМ) для обеспечения субстрата без токсичности
  * Использование хелатных агентов, улучшающих bioavailability бутирата (например, цитрат в низких концентрациях)
  * Избегать сильных хелатентов (например, фитатов) в среде при работе с гетерологичной экспрессией
- Процессные:
  * Мониторинг уровня бутирата через спектроскопические методы (ИК-спектроскопия, NMR)
  * Контроль уровня экспрессии гетерологичных конструктов через западноблоттинг или флюоресценцию
  * Комбинирование с другими добавками (например, магний для ACC1, цинк для транскрипции) для поддержания общего метаболического баланса
  * Использование буферных систем, минимизирующих осаждение при рабочем pH
