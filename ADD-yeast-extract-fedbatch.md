# Дрожжевый экстракт как стратегия смягчения ограничения азота в fed-batch культивации Yarrowia lipolytica

## Суть
Добавление дрожжевого экстракта в production фазе fed-batch культивирования смягчает негативные эффекты сильного ограничения азота на клеточный метаболизм, обеспечивая доступность аминокислот, витаминов и других факторов роста, необходимых для поддержания высокой продукции вторичных метаболитов, включая каннабиноидные предшественники и конечные продукты (THCVA, CBGVA, DVA).

## Детали
- **Механизм действия**: Дрожжевый экстракт предоставляет легко усваиваемые источники азота (пептиды, аминокислоты), витамины группы B и другие ростовые факторы, которые поддерживают метаболическую активность клеток даже при низком уровне неорганического азота в среде, предотвращая полную остановку роста и метаболизма.
- **Время подачи**: Оптимально добавлять периодически (например, каждые 24 часа) в production фазе после исчерпания начального неорганического азота для поддержания метаболического потока к вторичным продуктам.
- **Концентрация**: Обычно используется в диапазоне 2-5 г/л в зависимости от базовой среды и уровняднее ограничения азота.
- **Влияние на каннабиноидный путь**: Поддерживая достаточный уровень метаболической активности, дрожжевый экстракт помогает поддерживать экспрессию гетерологичных ферментов каннабиноидного пути (OLS, OAC, THCAS) и доступность предшественников (малонил-CoA, пропионил-CoA).
- **Совместимость**: Хорошо совместим с другими добавками (глицерин для NADPH/ацетил-CoA, пропионат для пропионил-CoA, малоновая кислота для малонил-CoA).

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через добавление дрожжевого экстракта в fed-batch можно:
- **Добавка в среду**:
  * Периодическое добавление дрожжевого экстракта (например, 3 г/л каждые 24 часа) в production фазе
  * Использование гидролизата дрожжей как альтернативного источника азота и витаминов
  * Комбинация с глицерином для одновременного обеспечения NADPH и смягчения азотного стресса
- **Процессные подходы**:
  * Мониторинг уровня ammonium в среде для определения времени добавления дрожжевого экстракта
  * Использование онлайн-мониторинга pH и DO как косвенных показателей метаболического состояния для оптимизации времени подачи
  * Интеграция с стратегиями пульсовой подачи углерода (глюкоза, глицерин) для сбалансированного питания

## Взаимодействия
→ усиливает: [[GEN-002]] (повышает малонил-CoA пул через поддержание метаболической активности), [[GEN-003]] (повышает изопреновый пул для прегненилtransfer), [[GEN-004]] (повышает пропионил-CoA пул для C3 модификации), [[ADD-glycerol]] (комплементарный источник ацетил-CoA и NADPH), [[ADD-propionate]] (предшественник пропионил-CoA), [[ADD-ma-2020-biorefinery]] (предоставляет стратегии для снижения метаболической нагрузки при экспрессии пути)
→ зависит от: наличия углеродного источника для энергии, функциональности гетерологично экспрессируемых ферментов каннабиноидного пути, достаточного уровня фосфатов и других минералов для роста
→ антагонизм с: чрезмерным добавлением ведущим к избыточному росту и подавлению вторичного метаболизма, потенциальным загрязнением неизвестными компонентами в дрожжевом экстракте

## Открытые вопросы
- Каков оптимальный профиль подачи дрожжевого экстракта в комбинации с конкретными углеродными источниками (глюкоза, глицерин, уксусная кислота) для максимизации производства конкретных каннабиноидов (THCVA, CBGVA, DVA)?
- Как дрожжевый экстракт влияет на экспрессию конкретных ферментов каннабиноидного пути (OLS, OAC, THCAS) в разных условиях культивации?
- Есть ли различия в効果 между разными типами дрожжевого экстракта (автолизат vs гидролизат) для каннабиноидного производства в Y. lipolytica?
- Можно ли использовать отходы пивоваренной или хлебопекарной промышленности как дешевый источник аналогичных питательных веществ вместо стандартного дрожжевого экстракта?

## Заметки
- Эта стратегия особенно полезна в длинных fed-batch ферментациях (>120 часов), где сильное ограничение азота может приводить к снижению метаболической активности и продуктивности.
- Дрожжевый экстракт предоставляет сложную смесь питательных веществ, что делает его трудным для точной дозировки, но эффективным для поддержания общего клеточного состояния.
- При работе с патогенными производственными штаммами необходимо обеспечить должную стерилизацию дрожжевого экстракта для предотвращения контаминации.
