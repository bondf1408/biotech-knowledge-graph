# Ацетил-CoA метаболический shortcut для производства поликетидов

## Суть
Метаболический shortcut ацетил-CoA в Yarrowia lipolytica обеспечивает альтернативный путь для формирования пула ацетил-CoA и малонил-CoA через расщепление ацетил-CoA и использование лизина/глутамата как предшественников. Это повышает доступность предшественников для поликетидного синтеза, включая производство дивариновой кислоты (DVA) и каннабиноидов, обходя некоторые ограничения традиционных путей.

## Детали
### Метаболические пути
1. **Разрубание ацетил-CoA**:
   - Ацетил-CoA → ацетат + CoA (через ацетил-CoA гидролазу или похожие ферменты)
   - Ацетат может быть повторно активирован до ацетил-CoA через ACS (ацетил-CoA синтетазу) или использоваться напрямую в некоторых путях

2. **Лизин/глутаматный путь**:
   - Лизин → ацетилацетил-CoA → ацетил-CoA + ацетоацетат (через лизин деградационный путь)
   - Глутамат → α-кетоглутарат → сукцинил-CoA → малоновой кисло-CoA (как описано в ADD-amino-acid-malonlyl-CoA)

3. **Интеграция с цитрат-ACL путем**:
   - Цитрат → ацетил-CoA + оксалоацетат (через ATP-citrate lyase, ACL)
   - Оксалоацетат может возвращаться в TCA цикл или использоваться для аминокислотного синтеза

### Ферменты и гены
- Ацетил-CoA гидролаза (ACH): YALI0Exxxxx или аналог
- ATP-citrate lyase (ACL): YALI0Fyyyyy или аналог (цитрат-ACL путь)
- Ацетил-CoA синтетаза (ACS): для реактивации ацетата
- Лизин килорeduктаза, глутаматдегидрогеназа: для аминокислотных путей

### Условия и кофакторы
- Требует CoA для реакций ацетил-CoA
- Может зависеть от ATP/ADP соотношения для ACL активности
- pH optimum около 7.0-7.5 для цитозольных ферментов
- Температурный optimum обычно 28-30°C для экспрессии в Y. lipolytica

## Рычаг повышения выхода
Для увеличения пула ацетил-CoA через метаболический shortcut можно:
- Генетически:
  * Overexpression ацетил-CoA гидролазы (ACH) для увеличения реакций разрубания
  * Overexpression ATP-citrate lyase (ACL) для усиления цитрат-ACL пути
  * Overexpression лизин деградационных ферментов для повышения преобразования лизина
  * Инженерирование транспортных систем для улучшенного поглощения лизина и глутамата
- Средовые:
  * Добавка лизина в концентрации 2-5 г/л как предшественник ацетил-CoA
  * Добавка глутамата в концентрации 5-15 г/л для поддержания аминокислотных путей
  * Комбинирование глюкозы с аминокислотами для синергетического эффекта на пул ацетил-CoA
  * Оптимизация времени добавки аминокислот в conjunction с фазой производства поликетидов
- Процессные:
  * Fed-batch стратегия подачи лизина или глутамата для поддержания стабильного уровня предшественников
  * Двухфазное культивирование: рост на глюкозе, производство на глюкозе + аминокислотах
  * Мониторинг уровня промежуточных метаболитов (ацетат, α-кетоглутарат) для коррекции условий

## Взаимодействия
→ усиливает: синтез ацетил-CoA для поликетидного пути, усиливает [[ENZ-ACC1]] (повышает субстрат для карбоксилирования), усиливает [[ENZ-OLS]] (повышает субстрат для тетракетид синтеза), усиливает [[ENZ-OAC]] (повышает субстрат для ciclization), усиливает [[GEN-002]] (повышает малонил-CoA пул через ACC1), усиливает [[CMP-001]] (THCVA), [[CMP-002]] (CBGVA), [[CMP-003]] (DVA), [[ADD-amino-acid-malonlyl-CoA]] (синергетический эффект на малонил-CoA производство), [[ADD-biotin-ACC1]] (кофактор для ACC1 активности), [[ADD-malonate]] (прямой предшественник малонил-CoA), [[ADD-propionate]] (прямой предшественник пропионил-CoA для DVA пути)
→ зависит от: доступности лизина и глутамата, функционирования TCA цикла и глиоксилатного цикла, доступности CoA и ATP для ацетил-CoA реакций, наличия транспортёров для аминокислот, [[ADD-glycerol]] (альтернативный источник ацетил-CoA через β-окисление), [[ADD-propionate]] (прямой предшественник пропионил-CoA для DVA пути), [[GEN-004]] (повышает пропионил-CoA пул для DVA синтеза), [[ENZ-ACC1]] (ключевой фермент для ацетил-CoA → малонил-CoA conversion)
→ антагонизм с: высокими концентрациями аминокислот приводящими к осмотическому стрессу, конкуренцией за транспортные системы между различными аминокислотами, перенаправлением потока в синтез аминокислот-derived продуктов вместо поликетидов, [HYPOTHESIS-ACETYL-CoA-DRAIN] (избыточная активация shortcut может снизить доступность ацетил-CoA для терпенoid синтеза через конкуренцию за ацетил-CoA пул)

## Заметки
- [INFERRED]: Многие параметры экстраполированы из Liu et al. 2019 и данных по аминокислотному метаболизму в других микроорганизмах из-за отсутствия прямых измерений в Y. lipolytica.
- Требуется экспериментальная валидация влияния лизина и глутамата на производство ацетил-CoA и поликетидов в Y. lipolytica.
- Acetyl-CoA metabolic shortcut предоставляет гибкость в обеспечении предшественников для поликетидного синтеза, особенно при ограниченном традиционном углеродном источнике или когда необходимо перенаправить метаболический поток от конкурирующих путей.
- Стратегия использования acetyl-CoA shortcut может быть особенно полезна в двухфазных системах, где фаза роста использует традиционные источники углерода, а фаза производства получает преимущество от аминокислотного补充 и ацетил-CoA разрубания.
