# Оливетол-синтаза (OLS) / Теракетид-синтаза (TKS) - кинетика и специфичность

## Суть
Оливетол-синтаза (OLS), также известная как тетракетид-синтаза (TKS), является ключевым ферментом поликетидного синтеза в каннабиноидном пути. Она катализирует конденсацию стартовой единицы ацил-CoA (обычно пропионил-CoA для DVA-пути) с тремя молекулами малонил-CoA для образования тетракетида, который затем циклизации дает оливетоловую кислоту или её аналоги. Специфичность OLS к стартовой единицы критически важна для определения конечного продукта - дивариновой кислоты (DVA) с C3 боковой цепью или её аналогов с различной длиной боковой цепи.

## Детали
- **Реакция**: Пропионил-CoA + 3 Малонил-CoA → Тетракетид + 3 CO₂ + 4 CoA
- **Механизм**: Последовательное добавление двухчекорочных единиц от малонил-CoA к стартовой ацил-CoA единице через ketoacyl-SH промежуточные
- **Специфичность starter unit**: Типичная растительная OLS (например, из Cannabis sativa) показывает предпочтение к пропионил-CoA (C3) как стартовой единице, но может принимать другие ацил-CoA с různой эффективностью:
  * Пропионил-CoA (C3): высокая эффективность, продуцирует оливетоловую кислоту (C6-ароматическое кольцо + C3 боковая цепь)
  * Ацетил-CoA (C2): низкая эффективность, продуцирует аналог с укороченной боковой цепью
  * Бутирил-CoA (C4): средняя эффективность, продуцирует C5-аналог оливетоловой кислоты
  * Гексанил-CoA (C6): низкая эффективность, продуцирует C7-аналог (как обсуждалось в ADD-hexanoate)
- **Металлозависимость**: Требует двухвалентных катионов (Mg²⁺ или Mn²⁺) для стабилизации структуры активного центра
- **Структура**: Гомодимер или гомотетрамер в зависимости от источника, каждая субъединица содержит активный центр с цистеиновым остатком для ацил-CoA связывания
- **Регуляция**: Может быть subject to feedback inhibition поликетидными продуктами или фосфорилированием

## Рычаг повышения выхода
Для увеличения выхода желаемого продукта через OLS можно:
- Средовые:
  * Оптимизация концентрации пропионил-CoA через предшественники (пропионат) и активацию (GEN-004)
  * Поддержание достаточного уровня малонил-CoA через overexpression ACC1 (GEN-002) или supplementation малоната (ADD-malonate)
  * Использование буферных систем для поддержания оптимального pH (6.0-7.5)
  * Добавка Mg²⁺ или Mn²⁺ для металлозависимой активности
- Инженерные подходы:
  * Directed evolution для изменения специфичности starter unit в сторону пропионил-CoA
  * Fusione OLS с регионспецифичными теараними для улучшения каналирования субстратов
  * Экспрессия в компартментах с высокой концентрацией предшественников (пероксисомам)
  * Оптимизация экспрессии через сильные промоторы (TEF1, hp4d) и оптимальные терминаторы
- Процессные:
  * Fed-batch подача пропионата для поддержания стабильного уровня пропионил-CoA
  * Двухфазное культивирование: фаза роста seguida production фазы
  * Мониторинг промежуточных продуктов через LC-MS для своевременной коррекции условий
