# hp4d промотор - сила и регуляция в Yarrowia lipolytica

## Суть
hp4d (high product formation 4d) промотор является сильным inducible промотором в Yarrowia lipolytica, активируемым при высокой плотности культивирования и ограничении питательных веществ. Его активность увеличивается в стационарной фазе роста, что делает его полезным для двухстадийного контроля экспрессии (рост vs продуцирование).

## Детали
- **Последовательность**: hp4d промотор в Y. lipolytica содержит элементы, ответственные за inducible экспрессию в ответ на питательный стресс и высокую клеточную плотность
- **Сила**: Относительная сила промотора hp4d в Y. lipolytica оценивается как comparable с промотором TEF1 и сильнее промотора ADH1
- **Регуляция**: hp4d экспрессия inducible, активируется при стационарной фазе роста, ограничении азота или высокой плотности культивирования; менее активна в экспоненциальной фазе
- **Применение в каннабиноидном пути**: Используется для inducible экспрессии ключевых ферментов пути на production фазе для снижения метаболического бремени во время роста
- **Ограничения**: Зависимость от стационарной фазы может замедлить общий производственный процесс; требует точного контроля перехода из экспоненциальной в стационарную фазу

## Рычаг повышения выхода
Для увеличения выхода каннабиноидов через hp4d-promoter-mediated экспрессию можно:
- Среды:
  * Использование двухстадийного культивирования: экспоненциальная фаза для роста биомассы, затем переход к стационарной фазе для inducible экспрессии
  * Оптимизация момента перехода на основе измерений биомассы и уровня питательных веществ
  * Использование чемиостатных систем для поддержания постоянной плотности клеток и контролируемого индуцирования
  * Добавление индукторов (например, метанола для POX2-промотора в гибридных системах) для точного контроля индуцирования
- Инженерные подходы:
  * Создание гибридных промоторов, объединяющих элементы hp4d с конститутивными промоторами (TEF1) для базового уровня экспрессии плюс inducible буст
  * Экспрессия хелпер-белков для улучшения сворачивания гетерологичных ферментов при inducible экспрессии
  * Модификация 5'UTR и 3'UTR областей для улучшения трансляции и стабильности мРНК в inducible системе
  * Использование codon-оптимизированных версий гетерологичных генов в сочетании с hp4d промотором для синергетического эффекта
- Процессные:
  * Fed-batch стратегия с контролируемым истощением питательных веществ для индуцирования hp4d промотора
  * Двухфазное культивирование: фаза роста в богатой среде, suivie production фазы в среде с ограниченным азотом или углеродом
  * Мониторинг уровня индуцирования через репортерные гены (例如, GFP под hp4d промотором)
  * Оптимизация времени индуцирования для максимального продукта przed onset метаболического бремени

## Заметки
- [INFERRED]: Многие параметры экстраполированы из данных по inducible промоторной силе в S. cerevisiae и общих принципов экспрессии в Y. lipolytica из-за отсутствия прямых измерений для каннабиноидного пути.

- hp4d промотор широко используется в метаболической инженерии Y. lipolytica для производства лимонной кислоты в стационарной фазе, подтверждая его inducible активность в этом организме.
- Комбинирование hp4d и TEF1 промоторов в гибридных системах позволяет достичь как высокой базовой экспрессии для роста ферментов, так и inducible буста для production фазы.
